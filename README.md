## 目录组织
```
.
├── config //配置文件
├── examples //测试代码
├── graph //相关图例
├── scripts //脚本文件
├── docs //文档
├── README.md //项目介绍
├── package-lock.json
├── package.json
└── todo
```

## 准备
执行如下命令

```bash
# 初始化安装
npm i -g lerna && lerna bootstrap
```

## 常用命令

```bash
# 范例
npm run start:vue2

# vue3 范例
npm run start:vue3
 
# 运行文档
npm run docs:dev
```
