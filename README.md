## 目录组织
```
.
├── config //配置文件
├── examples //测试代码
├── graph //相关图例
├── scripts //脚本文件
├── docs //文档
├── README.md //项目介绍
├── package-lock.json
├── package.json
└── todo.md 
```


## 使用方法
```bash
# 运行测试
npm run dev

# 运行某模块的官方示例
# 运行 vuex 的官方示例
npm run dev:official vuex
 
```
