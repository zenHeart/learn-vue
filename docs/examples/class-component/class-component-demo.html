Vue Class Component vs Composition API

Class Component（Vue 2 遗留）

使用 TypeScript Class + @Options 装饰器，逻辑分散在各个选项中。

// ❌ 已废弃写法（仅 Vue 2 支持）
@Component({ props: ['initialCount'] })
export default class Counter extends Vue {
  count = this.initialCount
  get doubleCount() { return this.count * 2 }

  @Watch('count')
  onChange() { console.log(this.count) }

  increment() { this.count++ }
  decrement() { this.count-- }
}
Composition API（Vue 3 官方推荐）

逻辑通过 Composition Functions 组织，相关逻辑集中管理。

// ✅ 推荐写法
<script setup lang="ts">
const props = defineProps<{ initialCount: number }>()
const count = ref(props.initialCount)
const doubleCount = computed(() => count.value * 2)

watch(count, (newVal) => {
  console.log(newVal)
})

function increment() { count.value++ }
function decrement() { count.value-- }
</script>
