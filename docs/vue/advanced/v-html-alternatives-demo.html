Vue v-html Alternatives Demo

Since v-html only renders raw HTML strings and cannot handle Vue components, this demo shows three main alternatives for dynamic component rendering.

1. Dynamic Component with <component :is>

The most common approach - Vue's built-in mechanism for dynamically rendering components.
