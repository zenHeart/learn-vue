# 4. 生命周期

> **目标**：理解 Vue 组件从创建到销毁的完整生命周期，掌握各阶段钩子的使用时机

---

## 4.2 生命周期图解

```
┌─────────────────────────────────────────────────────────────────────┐
│                      完整生命周期流程                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   new Vue()                                                         │
│       │                                                             │
│       ▼                                                             │
│   beforeCreate ──▶ 组件实例刚创建，data/methods 不可用              │
│       │                                                             │
│       ▼                                                             │
│   created ────▶ 实例创建完成，data/methods 可用，模板未渲染        │
│       │                                                             │
│       ▼                                                             │
│   Compile Template / Render Function                                 │
│       │                                                             │
│       ▼                                                             │
│   beforeMount ──▶ 模板编译完成，即将挂载                           │
│       │                                                             │
│       ▼                                                             │
│   mounted ────▶ DOM 挂载完成，可访问 $el                            │
│       │                                                             │
│       ▼                                                             │
│   [数据变化] ──────────────────┐                                    │
│       │                        │                                    │
│       ▼                        │                                    │
│   beforeUpdate ──▶ 响应式数据变化，DOM 更新前                      │
│       │                        │                                    │
│       ▼                        │                                    │
│   updated ──────▶ DOM 更新完成                                     │
│       │                        │                                    │
│       └────────────────────────┘                                    │
│                    (可循环)                                         │
│       │                                                             │
│       ▼                                                             │
│   [组件卸载]                                                        │
│       │                                                             │
│       ▼                                                             │
│   beforeUnmount ──▶ 组件即将卸载                                   │
│       │                                                             │
│       ▼                                                             │
│   unmounted ────▶ 组件卸载完成，DOM 移除，订阅取消                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 4.3 钩子详解

### 4.3.1 创建阶段

#### beforeCreate

```javascript
import { onBeforeCreate } from 'vue'

export default {
  beforeCreate() {
    // ❌ data/methods 不可用
    console.log(this.msg)  // undefined
    console.log(this.handleClick)  // undefined
  },
  setup() {
    onBeforeCreate(() => {
      // 同样，此时 data/methods 未初始化
    })
  }
}
```

**使用场景**：
- 初始化非响应式配置
- 第三方 SDK 初始化（需尽早执行）

#### created

```javascript
import { onCreated } from 'vue'

export default {
  data() {
    return { count: 0 }
  },
  created() {
    // ✅ data/methods 可用
    console.log(this.count)  // 0
    console.log(this.handleClick)  // function
  },
  setup() {
    onCreated(() => {
      // ✅ Composition API 中 setup 已执行
      console.log('Component created')
    })
  }
}
```

**使用场景**：
- 初始化组件状态
- 发起初始数据请求
- 设置事件监听

---

### 4.3.2 挂载阶段

#### beforeMount

```javascript
import { onBeforeMount } from 'vue'

export default {
  beforeMount() {
    // ✅ 模板已编译，DOM 未挂载
    console.log(this.$el)  // undefined
    console.log(document.querySelector('#app'))  // 存在但未挂载
  },
  setup() {
    onBeforeMount(() => {
      // 虚拟 DOM 创建完成，真实 DOM 即将挂载
    })
  }
}
```

#### mounted

```javascript
import { onMounted } from 'vue'

export default {
  mounted() {
    // ✅ DOM 挂载完成，可安全访问
    console.log(this.$el)  // <div id="app">...</div>
    this.$nextTick(() => {
      // DOM 完全更新后执行
    })
  },
  setup() {
    onMounted(() => {
      // 可访问真实 DOM
      const canvas = document.querySelector('canvas')
      // 初始化第三方库
    })
  }
}
```

**使用场景**：
- 访问 DOM 元素
- 初始化第三方库（图表、地图等）
- 启动定时器

---

### 4.3.3 更新阶段

#### beforeUpdate

```javascript
import { onBeforeUpdate } from 'vue'

export default {
  data() {
    return { count: 0 }
  },
  beforeUpdate() {
    // ✅ 数据已更新，DOM 未更新
    console.log(this.count)  // 最新值
    // 适合：获取更新前的 DOM 状态
  },
  setup() {
    onBeforeUpdate(() => {
      // 可获取 DOM 更新前的状态
    })
  }
}
```

#### updated

```javascript
import { onUpdated } from 'vue'

export default {
  updated() {
    // ✅ DOM 更新完成
    this.$nextTick(() => {
      // DOM 操作应放在这里
    })
  },
  setup() {
    onUpdated(() => {
      // 组件依赖的响应式数据更新后
    })
  }
}
```

**使用场景**：
- 响应式数据变化后的 DOM 操作
- 配合 `$nextTick` 使用

**⚠️ 注意**：避免在 updated 中修改数据，可能导致无限循环

---

### 4.3.4 卸载阶段

#### beforeUnmount

```javascript
import { onBeforeUnmount } from 'vue'

export default {
  beforeUnmount() {
    // ✅ 组件即将卸载
    clearInterval(this.timer)
    this.$off('event', this.handler)
  },
  setup() {
    onBeforeUnmount(() => {
      // 清理副作用
    })
  }
}
```

#### unmounted

```javascript
import { onUnmounted } from 'vue'

export default {
  setup() {
    const timer = setInterval(() => {
      console.log('tick')
    }, 1000)
    
    onUnmounted(() => {
      // ✅ 组件卸载完成，清理资源
      clearInterval(timer)
      console.log('Component unmounted')
    })
  }
}
```

**使用场景**：
- 清理定时器
- 取消事件订阅
- 取消网络请求
- 释放资源

## 4.4 Composition API 生命周期

| Options API | Composition API | 时机 |
|-------------|-----------------|------|
| `beforeCreate` | ❌ 不需要 | setup() 已替代 |
| `created` | ❌ 不需要 | setup() 已替代 |
| `beforeMount` | `onBeforeMount` | DOM 挂载前 |
| `mounted` | `onMounted` | DOM 挂载后 |
| `beforeUpdate` | `onBeforeUpdate` | DOM 更新前 |
| `updated` | `onUpdated` | DOM 更新后 |
| `beforeUnmount` | `onBeforeUnmount` | 组件卸载前 |
| `unmounted` | `onUnmounted` | 组件卸载后 |
| `errorCaptured` | `onErrorCaptured` | 错误捕获 |
| `renderTracked` | `onRenderTracked` | 依赖追踪（开发） |
| `renderTriggered` | `onRenderTriggered` | 触发更新（开发） |

## 4.5 完整示例

```vue
<script setup>
import { 
  ref, 
  onMounted, 
  onUpdated, 
  onUnmounted,
  onBeforeMount,
  onBeforeUpdate,
  onBeforeUnmount
} from 'vue'

const count = ref(0)
const log = (hook) => {
  console.log(`[${hook}] count = ${count.value}`)
}

onBeforeMount(() => log('onBeforeMount'))
onMounted(() => log('onMounted'))
onBeforeUpdate(() => log('onBeforeUpdate'))
onUpdated(() => log('onUpdated'))
onBeforeUnmount(() => log('onBeforeUnmount'))
onUnmounted(() => log('onUnmounted'))

let timer = null

onMounted(() => {
  timer = setInterval(() => {
    count.value++
  }, 1000)
})

onUnmounted(() => {
  clearInterval(timer)
})
</script>

<template>
  <div>
    <h1>Lifecycle Demo</h1>
    <p>Count: {{ count }}</p>
    <p>Open console to see lifecycle logs</p>
  </div>
</template>
```

**控制台输出**（每秒一次）：
```
[onBeforeMount] count = 0
[onMounted] count = 0
[onBeforeUpdate] count = 1
[onUpdated] count = 1
[onBeforeUpdate] count = 2
[onUpdated] count = 2
...
[onBeforeUnmount] count = 60
[onUnmounted] count = 60
```

## 4.6 父子组件生命周期顺序

```
┌─────────────────────────────────────────────────────────────────────┐
│                    父子组件生命周期执行顺序                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   创建阶段 (父 → 子):                                               │
│   ┌─────────────────────────────────────────────────────┐            │
│   │ 父 beforeCreate → 父 created → 父 beforeMount      │            │
│   │        ↓                                            │            │
│   │   子 beforeCreate → 子 created → 子 beforeMount    │            │
│   │        ↓                                            │            │
│   │      子 mounted                                     │            │
│   └─────────────────────────────────────────────────────┘            │
│   父 mounted                                                        │
│                                                                     │
│   更新阶段 (父 → 子 → 父):                                          │
│   ┌─────────────────────────────────────────────────────┐            │
│   │ 父 beforeUpdate                                     │            │
│   │        ↓                                            │            │
│   │   子 beforeUpdate → 子 updated                      │            │
│   │        ↓                                            │            │
│   │ 父 updated                                          │            │
│   └─────────────────────────────────────────────────────┘            │
│                                                                     │
│   卸载阶段 (父 → 子):                                               │
│   ┌─────────────────────────────────────────────────────┐            │
│   │ 父 beforeUnmount                                   │            │
│   │        ↓                                            │            │
│   │   子 beforeUnmount → 子 unmounted                   │            │
│   │        ↓                                            │            │
│   │ 父 unmounted                                       │            │
│   └─────────────────────────────────────────────────────┘            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 4.7 $nextTick 的作用

```vue
<script setup>
import { ref, nextTick } from 'vue'

const count = ref(0)
const pRef = ref(null)

const increment = async () => {
  count.value++
  
  // 此时 DOM 未更新
  console.log(pRef.value.textContent)  // "0"
  
  await nextTick()
  
  // DOM 更新后
  console.log(pRef.value.textContent)  // "1"
}
</script>

<template>
  <p ref="pRef">{{ count }}</p>
  <button @click="increment">+1</button>
</template>
```

## 4.8 错误捕获

```javascript
import { onErrorCaptured } from 'vue'

export default {
  setup() {
    onErrorCaptured((err, instance, info) => {
      console.error('Error captured:', err)
      console.error('Error info:', info)
      
      // 返回 false 阻止错误继续传播
      return false
    })
  }
}
```

## 4.9 关键知识点

| 钩子 | 说明 | 常见用法 |
|------|------|----------|
| `beforeCreate` | 实例创建前 | ❌ 很少使用 |
| `created` | 实例创建后 | 初始化、请求数据 |
| `beforeMount` | DOM 挂载前 | 最后准备 |
| `mounted` | DOM 挂载后 | 访问 DOM、初始化库 |
| `beforeUpdate` | DOM 更新前 | 获取更新前状态 |
| `updated` | DOM 更新后 | DOM 操作、配合 $nextTick |
| `beforeUnmount` | 卸载前 | 清理准备 |
| `unmounted` | 卸载后 | 清理定时器、订阅 |
