# 1. 响应式原理

> **目标**：深入理解 Vue 3 响应式系统的工作机制，掌握 Proxy/Reflect、Effect、依赖追踪的核心概念

---

## 1.1 什么是响应式？

响应式是一种编程范式，允许程序**声明式地**响应数据变化。

### 对比：Excel 电子表格

```
┌─────────────────────────────────────────────────────┐
│  A0 = 1    A1 = 2    A2 = A0 + A1 (自动计算)          │
│                                                     │
│  修改 A0 → A2 自动更新！                             │
└─────────────────────────────────────────────────────┘
```

### JavaScript 默认行为（无响应式）

```javascript
let A0 = 1
let A1 = 2
let A2 = A0 + A1

console.log(A2) // 3
A0 = 2
console.log(A2) // ❌ 仍然是 3，未自动更新！
```

**问题**：普通 JavaScript 变量修改后，需要手动重新计算依赖它的值。

## 1.2 响应式的核心要素

```
┌─────────────────────────────────────────────────────────────┐
│                     响应式系统三要素                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   1. Track (追踪)    ──  读取数据时，记录谁依赖了这个数据      │
│                                                             │
│   2. Trigger (触发) ──  修改数据时，通知所有依赖者更新       │
│                                                             │
│   3. Effect (副作用) ──  响应数据变化而执行的函数           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 伪代码实现

```javascript
// 伪代码展示核心概念
function reactive(obj) {
  return new Proxy(obj, {
    get(target, key) {
      track(target, key)  // 追踪：记录当前活跃的 Effect
      return Reflect.get(target, key)
    },
    set(target, key, value) {
      Reflect.set(target, key, value)
      trigger(target, key)  // 触发：通知所有依赖者
    }
  })
}

// 当数据变化时自动执行
function whenDepsChange(update) {
  const effect = () => {
    activeEffect = effect
    update()
    activeEffect = null
  }
  effect()
}
```

## 1.3 Vue 3 响应式 API

### ref vs reactive

```javascript
import { ref, reactive, computed, watchEffect } from 'vue'

// ref: 包装基本类型
const count = ref(0)
console.log(count.value)  // 0
count.value++
console.log(count.value)  // 1

// reactive: 包装对象
const state = reactive({
  name: 'Vue',
  version: 3
})
state.name = 'Vue 3'

// computed: 计算属性
const doubleCount = computed(() => count.value * 2)

// watchEffect: 响应式副作用
watchEffect(() => {
  console.log(`count is: ${count.value}`)
})
// 输出: count is: 1
```

### 对比表格

| 特性 | `ref` | `reactive` |
|------|-------|------------|
| 支持类型 | 基本类型 + 对象 | 仅对象 |
| 访问方式 | `.value` | 直接属性访问 |
| 解构丢失响应 | 是（需 `toRef`/`toRefs`） | 是（需 `toRef`/`toRefs`） |
| 替换整个对象 | 可以 | 需用 `Object.assign` |

## 1.4 依赖追踪机制

### 订阅者存储结构

```javascript
// WeakMap<target, Map<key, Set<effect>>>
const subs = new WeakMap()

function track(target, key) {
  if (activeEffect) {
    const effects = getSubscribersForProperty(target, key)
    effects.add(activeEffect)
  }
}

function trigger(target, key) {
  const effects = getSubscribersForProperty(target, key)
  effects.forEach(effect => effect())
}
```

### 执行流程图

```
┌──────────────────────────────────────────────────────────────┐
│                      依赖追踪执行流程                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   1. watchEffect(() => {                                     │
│         A2.value = A0.value + A1.value   ◀── 读取 A0, A1    │
│      })                                                      │
│                      │                                       │
│                      ▼                                       │
│   2. track(A0, 'value')  ──▶  记录当前 Effect 为 A0 的订阅者  │
│       track(A1, 'value')  ──▶  记录当前 Effect 为 A1 的订阅者  │
│                                                              │
│                      │                                       │
│                      ▼                                       │
│   3. A0.value = 2     ◀── 修改 A0                           │
│                                                              │
│                      │                                       │
│                      ▼                                       │
│   4. trigger(A0, 'value')  ──▶  执行所有 A0 的订阅者       │
│                                                              │
│                      │                                       │
│                      ▼                                       │
│   5. Effect 重新执行，A2.value 自动更新！                      │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 1.5 响应式限制

### 1.5.1 解构丢失响应

```javascript
const state = reactive({ count: 0 })

// ❌ 丢失响应式
const { count } = state
count++  // 不触发更新

// ✅ 使用 toRef 保持响应
import { toRef } from 'vue'
const count = toRef(state, 'count')
count.value++  // 触发更新
```

### 1.5.2 替换整个对象丢失响应

```javascript
const state = reactive({ count: 0 })

// ❌ 替换后丢失响应
state = reactive({ count: 1 })

// ✅ 使用 Object.assign 替换属性
Object.assign(state, { count: 1 })

// ✅ 使用 ref 替换整个对象
const state = ref({ count: 0 })
state.value = { count: 1 }  // 仍然是响应式的
```

### 1.5.3 响应式判断

```javascript
import { isRef, isReactive, isProxy } from 'vue'

const count = ref(0)
const state = reactive({ count: 0 })

isRef(count)       // true
isReactive(state)  // true
isProxy(state)     // true
isProxy(count)     // false（ref 不是 proxy）
```

## 1.6 调试响应式

```javascript
import { computed, onRenderTracked, onRenderTriggered } from 'vue'

export default {
  setup() {
    const count = ref(0)
    const doubled = computed(() => count.value * 2)

    // 调试依赖追踪
    onRenderTracked((event) => {
      console.log('依赖被追踪:', event)
      // debugger
    })

    // 调试触发更新
    onRenderTriggered((event) => {
      console.log('触发更新的依赖:', event)
      // debugger
    })

    return { count, doubled }
  }
}
```

### Debug Event 结构

```typescript
type DebuggerEvent = {
  effect: ReactiveEffect    // 触发更新的 Effect
  target: object           // 目标对象
  type: 'get' | 'set' | 'add' | 'delete' | 'clear'
  key: any                 // 被访问的 key
  newValue?: any           // 新值
  oldValue?: any          // 旧值
}
```

## 1.8 完整示例

```html
<!DOCTYPE html>
<html>
<head>
  <title>Vue 3 Reactivity Demo</title>
</head>
<body>
  <div id="app"></div>
  <script type="module">
    import { ref, reactive, computed, watchEffect } from 'https://unpkg.com/vue@3/dist/vue.esm-browser.js'
    
    // ref: 基本类型响应式
    const count = ref(0)
    
    // reactive: 对象响应式
    const state = reactive({
      name: 'Vue 3',
      items: ['a', 'b', 'c']
    })
    
    // computed: 计算属性
    const doubled = computed(() => count.value * 2)
    
    // watchEffect: 自动追踪副作用
    watchEffect(() => {
      console.log(`count: ${count.value}, doubled: ${doubled.value}`)
      console.log(`state.name: ${state.name}`)
    })
    
    // 触发更新
    count.value++      // console: count: 1, doubled: 2
    state.name = 'Vue 3.0'  // console: state.name: Vue 3.0
    
    console.log('Is ref?', count.value === 1)
  </script>
</body>
</html>
```

## 1.9 关键知识点

| 概念 | 说明 |
|------|------|
| **Proxy** | Vue 3 使用 Proxy 拦截对象属性读写 |
| **track** | 读取属性时，将当前 Effect 记录为依赖 |
| **trigger** | 写入属性时，通知所有依赖的 Effect 重新执行 |
| **activeEffect** | 当前正在执行的 Effect，用于 track 时记录依赖 |
| **WeakMap** | 存储 "target → key → effects" 的映射 |
