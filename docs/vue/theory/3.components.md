## 3.2 组件注册

### 3.2.1 全局注册

```javascript
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)

// 全局注册（整个应用可用）
app.component('MyComponent', {
  data() {
    return { count: 0 }
  },
  template: `<button @click="count++">Clicked {{ count }}</button>`
})

// 链式注册
app
  .component('ComponentA', ComponentA)
  .component('ComponentB', ComponentB)
  .component('ComponentC', ComponentC)

app.mount('#app')
```

**优点**：使用方便，无需导入
**缺点**：无法 tree-shaking，依赖关系不明确

### 3.2.2 局部注册

```vue
<!-- ComponentA.vue -->
<script setup>
import ComponentB from './ComponentB.vue'

// 局部注册（仅当前组件可用）
const components = {
  ComponentB
}
</script>

<template>
  <ComponentB />
</template>
```

```javascript
// 非 <script setup> 写法
import ComponentB from './ComponentB.vue'

export default {
  components: {
    ComponentB
  }
}
```

**优点**：利于 tree-shaking，依赖关系明确
**缺点**：需要手动导入

### 3.2.3 自动注册（`<script setup>`）

```vue
<script setup>
import ComponentA from './ComponentA.vue'
// 无需注册，直接使用
</script>

<template>
  <ComponentA />
</template>
```

## 3.3 组件渲染流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                      组件渲染流程                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   1. 创建 VNode                                                     │
│      ┌─────────────────────────────────────────────┐                │
│      │  Component VNode = {                        │                │
│      │    type: Component,                          │                │
│      │    props: { msg: 'hello' }                   │                │
│      │  }                                           │                │
│      └─────────────────────────────────────────────┘                │
│                              │                                       │
│                              ▼                                       │
│   2. 组件实例化（首次）                                              │
│      ┌─────────────────────────────────────────────┐                │
│      │  setup() → data() → 响应式系统初始化          │                │
│      │  生命周期钩子: beforeCreate, created         │                │
│      └─────────────────────────────────────────────┘                │
│                              │                                       │
│                              ▼                                       │
│   3. 渲染 VNode                                    │
│      ┌─────────────────────────────────────────────┐                │
│      │  setupResult.render() → Element VNode        │                │
│      │  或 template → compile → render function     │                │
│      └─────────────────────────────────────────────┘                │
│                              │                                       │
│                              ▼                                       │
│   4. 挂载 DOM                                        │
│      ┌─────────────────────────────────────────────┐                │
│      │  patch() → mount() → 真实 DOM              │                │
│      │  生命周期钩子: beforeMount, mounted         │                │
│      └─────────────────────────────────────────────┘                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 3.4 Props 和 Emits

### Props 定义

```vue
<script setup>
// 简洁定义
defineProps({
  title: String,
  count: {
    type: Number,
    default: 0,
    required: true
  },
  items: {
    type: Array,
    validator: (arr) => arr.length < 100
  }
})

// 使用解构（自动提取 attrs）
const { title = 'Default' } = defineProps({
  title: String
})
</script>
```

### Emits 定义

```vue
<script setup>
const emit = defineEmits(['click', 'update'])

// 使用
emit('click', { x: 1, y: 2 })
emit('update', newValue)
</script>
```

### 模板中使用

```vue
<template>
  <!-- 父组件 -->
  <ChildComponent 
    title="Hello" 
    :count="5"
    @update="handleUpdate"
  />
</template>
```

## 3.5 组件通信模式

```
┌─────────────────────────────────────────────────────────────────────┐
│                      组件通信模式                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   ┌─────────┐                          ┌─────────┐                 │
│   │  父组件  │◀──── Props 向下 ────────│  子组件  │                 │
│   └────┬────┘                          └────┬────┘                 │
│        │                                    │                       │
│        │──── Emit/Events 向上 ─────────────▶│                       │
│        │                                    │                       │
│        │──── Provide/Inject 跨级 ──────────▶│                       │
│        │                                    │                       │
│        │◀──── Expose + Ref 父访问子 ───────│                       │
│        │                                    │                       │
│        │──── Pinia/Vuex 全局状态 ──────────▶│                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.5.1 Props 向下传递

```vue
<!-- Parent.vue -->
<template>
  <Child :message="msg" :user="user" />
</template>

<script setup>
const msg = 'Hello'
const user = { name: 'John', age: 30 }
</script>
```

```vue
<!-- Child.vue -->
<script setup>
defineProps({
  message: String,
  user: Object
})
</script>

<template>
  <div>{{ message }}, {{ user.name }}!</div>
</template>
```

### 3.5.2 Emit 向上传递

```vue
<!-- Parent.vue -->
<template>
  <Child @greet="handleGreet" />
</template>

<script setup>
const handleGreet = (name) => {
  console.log(`Hello, ${name}!`)
}
</script>
```

```vue
<!-- Child.vue -->
<script setup>
const emit = defineEmits(['greet'])
const greet = () => emit('greet', 'Vue')
</script>

<template>
  <button @click="greet">Greet</button>
</template>
```

### 3.5.3 Provide/Inject 跨级通信

```vue
<!-- Ancestor.vue -->
<script setup>
import { provide } from 'vue'

provide('theme', 'dark')
provide('user', reactive({ name: 'John' }))
</script>

<template>
  <Child />
</template>
```

```vue
<!-- GrandChild.vue -->
<script setup>
import { inject } from 'vue'

const theme = inject('theme', 'light')  // 默认值
const user = inject('user')
</script>
```

## 3.6 插槽 (Slots)

### 基础用法

```vue
<!-- BaseCard.vue -->
<template>
  <div class="card">
    <slot>默认内容</slot>
  </div>
</template>
```

```vue
<!-- 使用 -->
<BaseCard>
  <h2>标题</h2>
  <p>内容</p>
</BaseCard>
```

### 具名插槽

```vue
<!-- Layout.vue -->
<div class="layout">
  <header><slot name="header" /></header>
  <main><slot /></main>
  <footer><slot name="footer" /></footer>
</div>
```

```vue
<!-- 使用 -->
<Layout>
  <template #header>标题</template>
  <template #default>主内容</template>
  <template #footer>页脚</template>
</Layout>
```

### 作用域插槽

```vue
<!-- DataList.vue -->
<script setup>
defineProps({
  items: Array
})
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.id">
      <slot :item="item" :index="item.id" />
    </li>
  </ul>
</template>
```

```vue
<!-- 使用 -->
<DataList :items="items">
  <template #default="{ item, index }">
    {{ index + 1 }}. {{ item.name }}
  </template>
</DataList>
```

## 3.7 动态组件

```vue
<script setup>
import Home from './Home.vue'
import About from './About.vue'

const tab = ref('Home')
const currentComponent = computed(() => {
  return tab.value === 'Home' ? Home : About
})
</script>

<template>
  <button @click="tab = 'Home'">Home</button>
  <button @click="tab = 'About'">About</button>
  
  <!-- 动态组件 -->
  <component :is="currentComponent" />
</template>
```

## 3.8 组件实例

```vue
<script setup>
import { ref, onMounted } from 'vue'

// 获取子组件实例
const childRef = ref(null)

onMounted(() => {
  // 访问子组件属性和方法
  console.log(childRef.value.count)
  childRef.value.reset()
})

// 暴露方法给父组件
defineExpose({
  count: 0,
  reset() {
    this.count = 0
  }
})
</script>
```

## 3.10 完整示例

### Todo 列表组件

```vue
<!-- TodoApp.vue -->
<script setup>
import { ref } from 'vue'
import TodoItem from './TodoItem.vue'

const todos = ref([
  { id: 1, text: 'Learn Vue', done: false },
  { id: 2, text: 'Build App', done: true }
])

const addTodo = (text) => {
  todos.value.push({
    id: Date.now(),
    text,
    done: false
  })
}

const removeTodo = (id) => {
  todos.value = todos.value.filter(t => t.id !== id)
}

const toggleTodo = (id) => {
  const todo = todos.value.find(t => t.id === id)
  if (todo) todo.done = !todo.done
}
</script>

<template>
  <div class="todo-app">
    <h1>Vue Todo App</h1>
    <TodoInput @add="addTodo" />
    <ul>
      <TodoItem
        v-for="todo in todos"
        :key="todo.id"
        :todo="todo"
        @toggle="toggleTodo"
        @remove="removeTodo"
      />
    </ul>
  </div>
</template>
```

```vue
<!-- TodoItem.vue -->
<script setup>
defineProps({
  todo: {
    type: Object,
    required: true
  }
})

const emit = defineEmits(['toggle', 'remove'])
</script>

<template>
  <li :class="{ done: todo.done }">
    <input
      type="checkbox"
      :checked="todo.done"
      @change="emit('toggle', todo.id)"
    />
    <span>{{ todo.text }}</span>
    <button @click="emit('remove', todo.id)">×</button>
  </li>
</template>

<style scoped>
.done span {
  text-decoration: line-through;
}
</style>
```

## 3.11 原理图解

```
┌─────────────────────────────────────────────────────────────────────┐
│                    组件实例与 VNode 关系                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   Component VNode                                                   │
│   ┌─────────────────────────────────────────┐                      │
│   │  {                                      │                      │
│   │    type: ComponentA,      ──────────────┼──┐                   │
│   │    props: { msg: 'hi' },                │  │                   │
│   │    children: { default: [...] }         │  │                   │
│   │  }                                      │  │                   │
│   └─────────────────────────────────────────┘  │                   │
│                                                 ▼                   │
│   Component Instance (组件实例)                │                   │
│   ┌─────────────────────────────────────────┐  │                   │
│   │  {                                      │◀─┘                   │
│   │    type: ComponentA,                    │                      │
│   │    appContext: ...,                     │                      │
│   │    setupResult: {                       │                      │
│   │      render: Function,                   │                      │
│   │      props: { msg: 'hi' },              │                      │
│   │      expose: {}                         │                      │
│   │    }                                    │                      │
│   │  }                                      │                      │
│   └─────────────────────────────────────────┘                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 3.12 关键知识点

| 概念 | 说明 |
|------|------|
| **全局注册** | `app.component()`，全局可用 |
| **局部注册** | `components` 选项，仅当前组件 |
| **Props** | 父 → 子 数据传递 |
| **Emit** | 子 → 父 事件传递 |
| **Provide/Inject** | 跨级组件通信 |
| **Slots** | 内容分发，父 → 子 HTML 片段 |
| **Dynamic Component** | `<component :is="">` 动态切换 |
| **defineExpose** | 暴露方法给父组件 |
