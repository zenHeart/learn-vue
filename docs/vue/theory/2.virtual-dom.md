# 2. 虚拟 DOM

> **目标**：理解虚拟 DOM 的概念、Vue 渲染管线，以及 VNode 与真实 DOM 的转换过程

---

## 2.1 什么是虚拟 DOM？

虚拟 DOM（Virtual DOM，简称 VDOM）是一种编程概念：

> 用 JavaScript 对象描述 UI 结构，与真实 DOM 同步时通过 Diff 算法最小化更新

### 对比：直接操作 DOM vs 虚拟 DOM

```
┌─────────────────────────────────────────────────────────────────────┐
│                    直接操作 DOM vs 虚拟 DOM                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   直接操作 DOM:                                                      │
│   ┌─────────┐    直接修改     ┌─────────┐                          │
│   │  Data   │ ──────────────▶ │   DOM   │  ❌ 每次修改触发重排重绘   │
│   └─────────┘                 └─────────┘                          │
│                                                                     │
│   虚拟 DOM:                                                         │
│   ┌─────────┐    修改     ┌──────────┐   Diff   ┌─────────┐       │
│   │  Data   │ ───────────▶ │  VNode   │ ────────▶ │   DOM   │       │
│   └─────────┘              └──────────┘          └─────────┘       │
│                                         │                            │
│                              批量对比，最小化真实 DOM 操作              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 2.2 VNode 结构

```javascript
// VNode 本质是一个 JavaScript 对象
const vnode = {
  type: 'div',                          // 标签名
  props: {                               // 属性
    id: 'app',
    class: 'container',
    onClick: () => handleClick()
  },
  children: [                           // 子节点
    { type: 'h1', props: {}, children: 'Hello' },
    { type: 'p', props: {}, children: 'Virtual DOM' }
  ]
}
```

### VNode 类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **Element VNode** | HTML/SVG 标签 | `{ type: 'div', ... }` |
| **Component VNode** | 组件 | `{ type: MyComponent, ... }` |
| **Text VNode** | 文本节点 | `{ type: Text, children: 'hello' }` |
| **Fragment VNode** | 片段 | `{ type: Fragment, children: [...] }` |
| **Comment VNode** | 注释 | `{ type: Comment, children: '<!-- -->'} }` |

## 2.3 渲染管线

```
┌─────────────────────────────────────────────────────────────────────┐
│                       Vue 渲染管线 (Render Pipeline)                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   ┌──────────────┐                                                │
│   │   模板代码   │   <template>                                   │
│   │  Template   │   <div>{{ message }}</div>                     │
│   └──────┬───────┘                                                │
│          │                                                         │
│          ▼ Compile (编译)                                          │
│   ┌──────────────┐                                                │
│   │  渲染函数    │   render() {                                   │
│   │  Render Fn   │     return h('div', message.value)             │
│   └──────┬───────┘    }                                           │
│          │                                                         │
│          ▼ Mount (挂载)                                            │
│   ┌──────────────┐                                                │
│   │  虚拟 DOM    │   VNode Tree                                   │
│   │  VNode Tree  │   ┌──div──┐                                    │
│   └──────┬───────┘   │ h1│p  │                                    │
│          │            └──┴───┘                                    │
│          │                                                         │
│          ▼ Patch (补丁)                                            │
│   ┌──────────────┐                                                │
│   │   真实 DOM   │   <div><h1></h1><p></p></div>                  │
│   │  Real DOM    │                                                │
│   └──────────────┘                                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 三阶段说明

| 阶段 | 说明 | 关键词 |
|------|------|--------|
| **Compile** | 模板 → 渲染函数 | 编译时优化 |
| **Mount** | 渲染函数 → VNode → 真实 DOM | 首次渲染 |
| **Patch** | 新旧 VNode 对比 → 最小化 DOM 更新 | Diff 算法 |

## 2.4 模板 vs 渲染函数

### 模板（Template）

```vue
<template>
  <div class="container">
    <h1 :class="titleClass">{{ title }}</h1>
    <p>{{ message }}</p>
    <button @click="handleClick">Click</button>
  </div>
</template>
```

**优点**：
- 接近 HTML，易于理解和维护
- 便于静态分析，编译器可优化
- 设计师友好

### 渲染函数（Render Function）

```javascript
import { h } from 'vue'

function render() {
  return h('div', { class: 'container' }, [
    h('h1', { class: titleClass.value }, title.value),
    h('p', message.value),
    h('button', { onClick: handleClick }, 'Click')
  ])
}
```

**适用场景**：
- 高度动态的渲染逻辑
- 需要程序化创建组件
- 底层组件库开发

## 2.5 Diff 算法核心

### 传统 Diff vs Vue 的优化 Diff

```
┌─────────────────────────────────────────────────────────────────────┐
│                      Diff 算法对比                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   传统 Diff (React):                                                │
│   ├── O(n³) 复杂度                                                  │
│   ├── 逐层对比所有节点                                              │
│   └── 性能开销大                                                     │
│                                                                     │
│   Vue 3 优化 Diff:                                                  │
│   ├── O(n) 近似线性复杂度                                           │
│   ├── 同层对比 + Key 优化                                           │
│   └── 编译时优化（Patch Flags）                                     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 相同节点的复用

```html
<!-- 不带 key: 位置变化时更新所有子节点 -->
<ul>
  <li v-for="item in items">{{ item.name }}</li>
</ul>

<!-- 带 key: 复用已有 DOM，减少移动 -->
<ul>
  <li v-for="item in items" :key="item.id">{{ item.name }}</li>
</ul>
```

### 静态提升（Static Hoisting）

```html
<!-- Vue 编译优化：静态节点只创建一次 -->
<template>
  <div>
    <h1>静态标题</h1>           <!-- 编译后: hoist -->
    <p>静态内容</p>              <!-- 编译后: hoist -->
    <span>{{ dynamic }}</span>   <!-- 每次渲染创建 -->
  </div>
</template>
```

## 2.6 Block 概念

Block 是 Vue 3 编译优化的核心概念：

> **Block**：模板中结构稳定的部分

```
┌─────────────────────────────────────────────────────────────────────┐
│                         Block 树结构                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   <div>                          <!-- Block Root (稳定结构)          │
│     <div>static</div>            <!-- 静态节点 (跳过 Diff)           │
│     <div>{{ dynamic }}</div>      <!-- 动态节点 (追踪)               │
│     <div v-if="show">            <!-- New Block (v-if 创建)         │
│       <span>{{ msg }}</span>      <!-- 动态节点                      │
│     </div>                                                         │
│   </div>                                                              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 树形扁平化（Tree Flattening）

```javascript
// 编译后只有动态节点被追踪
const vnode = createElementBlock('div', {}, [
  /* 只有 dynamic 和 msg 两个动态节点 */
  dynamicNode,    // :class 或 {{ }}
  msgNode         // {{ }}
])
```

## 2.7 完整示例

### 渲染函数示例

```html
<!DOCTYPE html>
<html>
<head>
  <title>Vue 3 Render Function Demo</title>
</head>
<body>
  <div id="app"></div>
  <script type="module">
    import { createApp, h, ref } from 'https://unpkg.com/vue@3/dist/vue.esm-browser.js'
    
    const App = {
      setup() {
        const message = ref('Hello Virtual DOM!')
        const count = ref(0)
        
        const handleClick = () => {
          count.value++
          message.value = `Clicked ${count.value} times`
        }
        
        // 使用 h() 创建 VNode
        return () => h('div', { class: 'container' }, [
          h('h1', { style: 'color: blue' }, message.value),
          h('button', { onClick: handleClick }, 'Click me'),
          h('p', `Count: ${count.value}`)
        ])
      }
    }
    
    createApp(App).mount('#app')
  </script>
</body>
</html>
```

### VNode 对比示例

```javascript
// 旧 VNode
const oldVnode = {
  type: 'div',
  props: { id: 'app' },
  children: [
    { type: 'p', children: 'Hello' }
  ]
}

// 新 VNode
const newVnode = {
  type: 'div',
  props: { id: 'app', class: 'active' },  // props 变化
  children: [
    { type: 'p', children: 'World' }       // children 变化
  ]
}

// Diff 结果：
// 1. div props 更新: id → id + class
// 2. p children 更新: 'Hello' → 'World'
```

## 2.8 虚拟 DOM 优缺点

### 优点

| 优点 | 说明 |
|------|------|
| **声明式** | 描述 UI 结构，不关心具体 DOM 操作 |
| **跨平台** | VNode 可渲染到 DOM、Native、Server |
| **性能优化** | 批量更新，最小化 DOM 操作 |
| **开发体验** | 直接操作 JavaScript 对象，易于调试 |

### 缺点

| 缺点 | 说明 |
|------|------|
| **内存开销** | 需要维护 VNode 树，额外内存 |
| **首次渲染** | 多一层转换，略微慢于直接操作 |
| **非最优** | 对于简单更新，虚拟 DOM 开销可能更大 |

### Vue 的优化策略

1. **编译时优化**：Patch Flags、静态提升、Block 分支
2. **运行时优化**：Tree Flattening、事件缓存
3. **SSR 优化**：部分 hydration

## 2.10 关键知识点

| 概念 | 说明 |
|------|------|
| **VNode** | 虚拟节点，描述 UI 的 JavaScript 对象 |
| **h()** | 创建 VNode 的辅助函数 |
| **Mount** | 将 VNode 转换为真实 DOM |
| **Patch** | 对比新旧 VNode，更新 DOM |
| **Diff** | 找新旧 VNode 差异的算法 |
| **Block** | 结构稳定的模板部分，用于优化 Diff |
| **Patch Flag** | 编译时标记动态内容类型 |
