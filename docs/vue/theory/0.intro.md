# Vue 核心原理导论

## 概述

Vue 是一款渐进式 JavaScript 框架，其核心设计理念是通过简洁的 API 提供高效的响应式数据绑定和组合式视图组件。

```
┌─────────────────────────────────────────────────────────────┐
│                        Vue 应用                            │
├─────────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐    │
│  │   响应式     │  │    模板      │  │    渲染      │    │
│  │  Reactivity  │  │   Template   │  │   Renderer   │    │
│  └──────────────┘  └──────────────┘  └──────────────┘    │
│         ↑                ↑                ↑               │
│         └────────────────┼────────────────┘               │
│                          ↓                                │
│              ┌──────────────────────┐                     │
│              │     虚拟 DOM         │                     │
│              │    Virtual DOM      │                     │
│              └──────────────────────┘                     │
│                          ↓                                │
│              ┌──────────────────────┐                     │
│              │      真实 DOM        │                     │
│              │      Real DOM        │                     │
│              └──────────────────────┘                     │
└─────────────────────────────────────────────────────────────┘
```

## Vue 核心模块

### 1. 响应式系统 (Reactivity)

Vue 的响应式系统是其核心特性之一，能够追踪数据变化并自动更新视图。

#### Vue 2: Object.defineProperty

```js
// Vue 2 响应式原理
function defineReactive(obj, key, val) {
  Object.defineProperty(obj, key, {
    enumerable: true,
    configurable: true,
    get: function() {
      // 收集依赖
      return val;
    },
    set: function(newVal) {
      if (val === newVal) return;
      // 触发更新
      val = newVal;
      notify();
    }
  });
}
```

#### Vue 3: Proxy

```js
// Vue 3 响应式原理
function reactive(obj) {
  return new Proxy(obj, {
    get(target, key) {
      track(target, key);  // 收集依赖
      return Reflect.get(target, key);
    },
    set(target, key, value) {
      const result = Reflect.set(target, key, value);
      trigger(target, key);  // 触发更新
      return result;
    }
  });
}
```

#### 响应式流程

```
数据变更 → Setter 触发 → Dep.notify() → Watcher.update() → 队列处理 → 视图更新
    ↓
  批量更新（nextTick）
```

### 2. 虚拟 DOM (Virtual DOM)

虚拟 DOM 是真实 DOM 的 JavaScript 对象表示，Vue 通过对比新旧虚拟 DOM 来高效更新真实 DOM。

#### 虚拟节点结构

```js
// VNode 结构
const vnode = {
  type: 'div',
  props: {
    id: 'app',
    class: 'container',
    onClick: handleClick
  },
  children: [
    { type: 'h1', props: {}, children: 'Hello Vue' },
    { type: 'p', props: {}, children: 'Welcome' }
  ]
};
```

#### Diff 算法流程

```
新旧 VNode 对比
       ↓
┌──────┴──────┐
│  同层级比较   │
└──────┬──────┘
       ↓
┌──────┴──────┐
│ key 存在？   │──否──→ 替换整个节点
└──────┬──────┘
       ↓是
┌──────┴──────┐
│ 类型相同？   │──否──→ 替换属性/内容
└──────┬──────┘
       ↓是
┌──────┴──────┐
│ 递归比较子节点 │
└─────────────┘
```

### 3. 组件系统 (Component)

组件是 Vue 的核心构建块，封装可复用的视图和逻辑。

#### 组件注册

```js
// 全局注册
Vue.component('my-button', {
  template: '<button @click="handleClick">{{ text }}</button>',
  props: {
    text: String
  },
  methods: {
    handleClick() {
      this.$emit('click');
    }
  }
});

// 局部注册
const MyComponent = {
  template: '<div>Local Component</div>'
};
```

#### 组件通信

| 方式 | 适用场景 | API |
|------|---------|-----|
| Props向下 | 父→子传值 | props |
| $emit向上 | 子→父事件 | $emit |
| Provide/Inject | 跨级传值 | provide/inject |
| Vuex/Pinia | 全局状态 | store |

### 4. 生命周期 (Lifecycle)

```
┌─────────────────────────────────────────────────────────────────────┐
│                        Vue 实例生命周期                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  beforeCreate ──→ created ──→ beforeMount ──→ mounted ──→         │
│       ↓                                      ↓                      │
│  实例初始化                          DOM 挂载完成                    │
│                                                                      │
│                      beforeUpdate ──→ updated ──→                   │
│                           ↓                                         │
│                      数据变更重新渲染                                │
│                                                                      │
│                      beforeUnmount ──→ unmounted                     │
│                           ↓                                         │
│                      组件卸载清理                                    │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

#### 关键生命周期说明

| 钩子 | 阶段 | 用途 |
|------|------|------|
| beforeCreate | 实例初始化 | 设置 loading、初始化非响应式数据 |
| created | 实例创建完成 | 异步数据请求、修改 data |
| beforeMount | 挂载前 | 最后一次 DOM 操作机会 |
| mounted | 挂载完成 | 获取 DOM、启动定时器、绑定事件 |
| beforeUpdate | 更新前 | 访问现有 DOM |
| updated | 更新完成 | 避免更新状态（可能死循环） |
| beforeUnmount | 卸载前 | 清理定时器、解绑事件 |
| unmounted | 卸载完成 | 彻底清理 |

### 5. 模板编译 (Template Compilation)

```
模板字符串
     ↓
┌────────────┐
│   Parser   │  解析器 - 解析成 AST
└────────────┘
     ↓
┌────────────┐
│  Optimize   │  优化器 - 标记静态节点
└────────────┘
     ↓
┌────────────┐
│   Codegen  │  代码生成器 - 生成 render 函数
└────────────┘
     ↓
render() / h()
```

#### 编译产物示例

```js
// 模板
<div id="app" @click="handleClick">
  {{ message }}
</div>

// 编译产物
render() {
  return h('div', {
    id: 'app',
    onClick: this.handleClick
  }, this.message);
}
```

## Vue 2 vs Vue 3 核心差异

| 特性 | Vue 2 | Vue 3 |
|------|-------|-------|
| 响应式原理 | Object.defineProperty | Proxy |
| 组件定义 | Options API | Composition API |
| 虚拟 DOM | 基于 Snabbdom | 性能优化的 VNode |
| TypeScript 支持 | 部分支持 | 完整支持 |
| 打包体积 | 较大 | 更小（Tree-shaking）|
| 性能 | Good | Better |
