## 数组响应式边界

### Vue 2 — Object.defineProperty 的限制

Vue 2 使用 `Object.defineProperty` 劫持对象属性，对数组的监听能力有限：

| 操作 | 响应式 | 说明 |
|------|--------|------|
| `push/pop/shift/unshift/splice` | ✅ | 数组方法，Vue 劫持了这些方法 |
| `arr[0] = x`（直接索引赋值） | ❌ | 无法触发更新 |
| `arr.length = 0`（直接修改长度） | ❌ | 无法触发更新 |
| `arr = [...newArr]`（整体替换） | ✅ | 引用变化，一定触发 |

### 常见问题：unshift 后视图不更新

**场景：** 在 Vue 2 中使用 `unshift` 向前插入数据，发现视图不更新。

**原因分析：**

```js
// ❌ 如果是直接索引赋值，Vue 检测不到
this.items[0] = { name: 'new' }; // 不触发更新

// ✅ unshift 本身是响应式的，会触发更新
this.items.unshift({ name: 'new' }); // 正常更新

// ⚠️ 但如果 items 本身不是响应式的（初始化问题）
this.items = [];  // 初始化为空数组
this.items = ['a']; // 引用替换，OK
this.items.unshift('b'); // 如果 items 脱离了响应式系统，则不更新
```

**正确解法：**

```js
// 1. Vue.set — Vue 2 推荐
Vue.set(this.items, 0, { name: 'new' });

// 2. 数组整体替换 — Vue 2/3 都适用
this.items = [{ name: 'new' }, ...this.items];

// 3. splice — 响应式方法
this.items.splice(0, 0, { name: 'new' });
```

### Vue 3 — Proxy 的改进

Vue 3 使用 `Proxy` 替代 `defineProperty`，对数组的监听更全面：

| 操作 | 响应式 | 说明 |
|------|--------|------|
| `push/pop/shift/unshift/splice` | ✅ | 仍然响应式 |
| `arr[0] = x`（直接索引赋值） | ✅ | Proxy 可以拦截 |
| `arr.length = 0` | ⚠️ | 仍需通过方法触发 |

### 通用最佳实践

1. **优先使用响应式方法**：`push/unshift/splice`，不要直接操作索引
2. **Vue 2 中为数组添加元素**：使用 `Vue.set(array, index, value)`
3. **需要强制更新时**：使用数组整体替换 `this.items = [...newItems]`
4. **嵌套对象中的数组**：确保初始化时就是响应式数组，避免后期引用替换
