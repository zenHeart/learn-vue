## 二、各模块说明

### 1. 响应式系统 (Reactivity)

**核心问题**：数据变化时，视图如何自动更新？

**解决方案**：
- 使用 Proxy 拦截对象属性的读写
- Track（追踪）依赖关系
- Trigger（触发）更新

**文档**：[深入响应式原理](./1.reactivity.md)

### 2. 虚拟 DOM (Virtual DOM)

**核心问题**：组件状态变化时，如何高效更新 DOM？

**解决方案**：
- 用 VNode 描述 UI 结构
- Mount：将 VNode 渲染为真实 DOM
- Patch：对比新旧 VNode，最小化 DOM 操作

**文档**：[虚拟 DOM 原理](./2.virtual-dom.md)

### 3. 组件系统 (Components)

**核心问题**：如何构建可复用、可组合的 UI 模块？

**解决方案**：
- 组件注册（全局/局部）
- Props/Emit 通信
- Slots 内容分发
- Provide/Inject 跨级通信

**文档**：[组件系统详解](./3.components.md)

### 4. 生命周期 (Lifecycle)

**核心问题**：组件从创建到销毁，各阶段的执行顺序是什么？

**关键钩子**：
- `beforeCreate` / `created` - 创建阶段
- `beforeMount` / `mounted` - 挂载阶段
- `beforeUpdate` / `updated` - 更新阶段
- `beforeUnmount` / `unmounted` - 卸载阶段

**文档**：[生命周期详解](./4.lifecycle.md)

### 5. 编译优化 (Compilation)

**核心问题**：模板如何被编译？有哪些运行时优化？

**优化策略**：
- 静态提升 (Hoisting)
- Patch Flags
- Block 树
- 事件监听器缓存

**文档**：[编译优化详解](./5.compilation.md)

## 三、工作流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                      Vue 3 应用工作流程                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   1. 编写模板                                                       │
│      <template>                                                     │
│        <div :class="theme">                                        │
│          <h1>{{ title }}</h1>                                      │
│          <ChildComponent :msg="message" @update="handleUpdate" />  │
│        </div>                                                      │
│      </template>                                                   │
│                                                                     │
│                        │                                            │
│                        ▼ Compile (构建时)                           │
│                                                                     │
│   2. 生成渲染函数                                                   │
│      function render(ctx) {                                       │
│        return h('div', { class: ctx.theme }, [                     │
│          h('h1', ctx.title),                                       │
│          h(ChildComponent, { msg: ctx.message })                   │
│        ])                                                          │
│      }                                                             │
│                                                                     │
│                        │                                            │
│                        ▼ Mount (运行时)                             │
│                                                                     │
│   3. 创建真实 DOM                                                  │
│      <div class="dark">                                             │
│        <h1>Hello</h1>                                              │
│        <!-- ChildComponent -->                                      │
│      </div>                                                        │
│                                                                     │
│                        │                                            │
│                        ▼ Reactive (响应式)                          │
│                                                                     │
│   4. 数据变化 → 自动更新                                            │
│      title = 'Updated'  ───▶  patch()  ───▶  DOM 更新               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
