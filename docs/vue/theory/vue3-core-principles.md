## 核心技术点概览

| 知识点 | 目标 | 核心价值 |
|--------|------|----------|
| 响应式原理 | 理解 Proxy + Effect 工作机制 | 掌握数据驱动视图的核心 |
| 虚拟 DOM | 理解 VNode 创建与 Diff 算法 | 掌握高效 DOM 更新策略 |
| 组件系统 | 掌握组件注册、通信、渲染流程 | 构建可复用应用架构 |
| 生命周期 | 理解组件各阶段钩子与执行时机 | 正确管理副作用与资源 |
| 编译优化 | 理解模板编译优化策略 | 提升运行时性能 |
