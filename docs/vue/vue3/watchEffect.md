# wacthEffect 使用详解

## 知识点
1. watchEffect 绑定监听器
   1. 申明时便会触发一次
   2. 入参提供一个挂载器，可以注入校验函数，检验函数
      1. 函数挂在后，下次监听器运行时触发
      2. 只支持挂载单一函数，每次重新执行时，上次挂载会被替换
      3. 执行顺序
         1. 首次执行挂载回调
         2. 若挂载回调挂载了校验函数则触发
         3. 若挂载了新的校验函数则替换之前的挂在函数下次触发
   3. 支持配置 `options`, flush, 未看到差异？？？
   4. 返回的回调可以手动调用阻止监听
