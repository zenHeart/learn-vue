# 生命周期钩子示例

这个示例展示了 Vue 3 中组合式 API 的生命周期钩子使用方法。

## 功能说明
- 使用 on* 方式注册生命周期钩子
- 展示各个生命周期钩子的执行顺序
- 生命周期钩子的调试功能

## 学习要点
- 组合式 API 的生命周期钩子
- 生命周期钩子的执行时机
- 调试钩子的使用
- 错误捕获钩子的使用

## 生命周期钩子
- onBeforeMount - 组件挂载前
- onMounted - 组件挂载后
- onBeforeUpdate - 组件更新前
- onUpdated - 组件更新后
- onBeforeUnmount - 组件卸载前
- onUnmounted - 组件卸载后
- onErrorCaptured - 错误捕获
- onRenderTriggered - 渲染触发调试
