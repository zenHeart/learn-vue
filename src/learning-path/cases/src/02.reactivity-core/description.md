# 响应式核心：动态依赖与批处理

## 目标与起点

你能用 Proxy、依赖集合和微任务实现普通属性的订阅、分支依赖清理、去重调度和停止。 本例是基于公开技术机制设计的教学任务，不是某企业内部项目。前置：函数、对象、Promise，以及 Vue 的基本模板与状态绑定。先独立完成，再查看“显示提示”中的参考解法。

## 先预测，再运行

两次同步写入为什么只观察一次？切到 b 后改 a 为什么不应再触发？停止时已排队的任务怎么办？

在编辑器中修改 `model.js`，用界面的实际结果核对预测。保留一段自己的解释；照着参考解法完成的尝试只算练习，不算无提示通过。

## 机制与常见错误

读取时连接属性与当前 effect；每轮执行先删除旧连接，再收集实际读取。微任务队列对同一 runner 去重。

需要反驳的误解：依赖只能增加；所有响应式写入都必须立即执行回调。
