# 异步竞态：让最新意图决定页面

## 目标与起点

你能稳定复现旧响应覆盖新结果，并处理过期成功、过期错误和卸载后响应。 本例是基于公开技术机制设计的教学任务，不是某企业内部项目。前置：函数、对象、Promise，以及 Vue 的基本模板与状态绑定。先独立完成，再查看“显示提示”中的参考解法。

## 先预测，再运行

先发旧请求、后发新请求，新请求先完成，最后应保留哪条？旧请求失败应该覆盖最新结果吗？

在编辑器中修改 `model.js`，用界面的实际结果核对预测。保留一段自己的解释；照着参考解法完成的尝试只算练习，不算无提示通过。

## 机制与常见错误

用意图版本区分请求新旧，提交前判断是否仍有效。取消请求可减少资源消耗，版本检查保证不能取消时的数据正确性。

需要反驳的误解：最后返回的一定是用户最新想要的；捕获异常后直接写 error 永远正确。
