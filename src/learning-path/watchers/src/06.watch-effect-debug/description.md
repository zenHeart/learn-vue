# watchEffect 调试示例

这个示例展示了 Vue 3 中 watchEffect 的调试功能，包括 onTrack 和 onTrigger 钩子的使用。

## 功能说明
- 使用 onTrack 追踪依赖收集
- 使用 onTrigger 追踪触发更新
- 组件生命周期钩子的使用
- 响应式数据的调试

## 学习要点
- watchEffect 的调试选项
- 依赖收集的追踪
- 更新触发的追踪
- 组件生命周期的调试

## 关键特性
- onTrack 钩子用于追踪依赖收集
- onTrigger 钩子用于追踪更新触发
- 组件生命周期钩子的调试
- 响应式数据的调试机制
