# 响应式原理示例

这个示例展示了 Vue 3 响应式系统的一个重要特性：reactive 会直接修改传入的初始对象。这个特性需要我们在使用时特别注意，避免直接操作原始对象。

## 示例功能
- 展示 reactive 对原始对象的修改
- 对比直接操作原始对象和响应式对象的效果
- 演示响应式系统的工作原理

## 关键学习点
- reactive 的工作原理
- 响应式对象与原始对象的关系
- 避免直接操作原始对象的最佳实践
- 响应式系统的实现机制

## 学习目标
1. 理解 reactive 对原始对象的修改机制
2. 掌握响应式对象的使用注意事项
3. 了解 Vue 3 响应式系统的基本原理
4. 学会正确处理响应式对象和原始对象的关系
