# Vue 基础概念

本目录包含了 Vue 3 的基础概念示例，帮助开发者理解 Vue 的核心概念和基本用法。

## 目录结构

```
basics/
├── README.md (当前文件)
├── index.md (入口页面)
└── src/
    ├── 01.basic/ (基础组件示例)
    ├── 02.counter/ (计数器示例)
    ├── 03.create-app/ (应用创建)
    ├── 04.basic-render/ (基础渲染)
    ├── 05.compile/ (编译相关)
    └── 06.template-expression/ (模板表达式)
```

## 示例说明

1. **基础组件示例**：展示 Vue 组件的基本结构和用法。
2. **计数器示例**：一个简单的计数器应用，展示数据绑定和事件处理。
3. **应用创建**：展示如何创建和挂载 Vue 应用。
4. **基础渲染**：展示 Vue 的模板渲染机制。
5. **编译相关**：展示 Vue 的编译过程和相关概念。
6. **模板表达式**：展示 Vue 模板中的表达式用法。

## 学习目标

- 理解 Vue 组件的基本结构
- 掌握数据绑定和事件处理
- 了解 Vue 应用的创建和挂载过程
- 理解 Vue 的模板渲染机制
- 掌握模板表达式的使用
