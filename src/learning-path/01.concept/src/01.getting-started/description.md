# Vue 3 入门

这是 Vue 3 基础学习路径的第一步，我们将学习如何创建一个简单的 Vue 3 应用程序。

## 组合式 API

Vue 3 引入了组合式 API (Composition API)，它提供了一种更灵活的方式来组织组件逻辑。在本示例中，我们使用 `setup()` 函数来:

1. 创建响应式状态
2. 定义方法
3. 返回模板需要的数据和函数

## 响应式状态

在本例中，我们使用 `reactive()` 创建一个响应式对象，当对象属性变化时，视图会自动更新。

## 计算属性

`computed()` 函数用于创建计算属性，它会自动追踪依赖并在依赖变化时更新。

尝试点击按钮，观察计数和它的两倍值如何变化。
