# 基础组件示例

这个示例展示了 Vue 组件的基本结构和用法。通过一个简单的计数器应用，你将学习到：

1. Vue 组件的基本结构（template、script）
2. 响应式数据的使用（reactive）
3. 计算属性的使用（computed）
4. 事件处理（@click）
5. 模板语法（{{ }} 插值）

## 示例说明

这个示例实现了一个简单的计数器：
- 显示当前计数值
- 显示计数值的两倍
- 点击按钮增加计数值

## 关键概念

- **响应式数据**：使用 `reactive` 创建响应式对象
- **计算属性**：使用 `computed` 创建基于响应式数据的计算属性
- **事件处理**：使用 `@click` 绑定点击事件
- **模板语法**：使用 `{{ }}` 在模板中显示数据

## 学习目标

- 理解 Vue 组件的基本结构
- 掌握响应式数据的使用
- 学习计算属性的创建和使用
- 了解事件处理的基本方法
