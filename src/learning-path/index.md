# Vue 学习路径

欢迎来到 Vue 学习路径！这里提供了不同主题的 Vue 学习路径，帮助你系统地掌握 Vue 的各个方面。

## 可用学习路径

### [响应式编程 (Reactivity)](/learning-path/reactivity/)

学习 Vue 的响应式系统，包括：

- [Watch API](/learning-path/reactivity/#01.watch) - 了解如何监听响应式数据的变化
- [WatchEffect API](/learning-path/reactivity/#02.watchEffect) - 学习更简洁的响应式监听方式

### [Vue 理论基础 (Theory)](/learning-path/theory/)

了解 Vue 的基础理论知识：

- [基础概念](/learning-path/theory/#01.xxx) - 掌握 Vue 的核心概念和原理

### [性能优化 (Performance)](/learning-path/performance/)

学习 Vue 在大型数据结构下的典型性能陷阱：

- [列表投影性能](/learning-path/performance/#01.reactive-spread-projection) - spread 响应式代理的依赖收集成本与 toRaw 快照派生
