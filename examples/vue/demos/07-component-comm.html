通信方式对比

方式方向使用场景代码示例
Props / $emit 父 → 子 / 子 → 父 父子直接通信 :count / emit('update')
$refs 父 → 子组件实例 需要调用子组件方法 this.$refs.child.method()
provide / inject 祖先 → 后代 深层传值，避免逐层 prop provide('key', val)
Vuex / Pinia 任意组件 全局状态管理 store.state.count
EventBus / mitt 任意组件 跨组件通信（简单场景） bus.emit('event', data)
slot 父 → 子（传递模板） 内容分发，布局组件 <slot>

provide/inject 原理

// 父组件
provide() {
  return {
    theme: this.theme,        // 简单值（不是响应式的！）
    user: this.user          // 直接提供响应式对象
  }
}

// 子孙组件
inject: ['theme', 'user']

// 或者
const { theme, user } = inject({
  theme: 'defaultTheme',
  user: { from: 'user', default: {} }
});

// ⚠️ 注意：provide 本身不是响应式的
// 响应式需要 provide() { return reactive({...}) }

$refs 访问

// 父组件模板中给子组件加 ref 属性
<ChildComponent ref="childRef" />

// 父组件中访问
this.$refs.childRef    // → 子组件实例（Vue 2）
this.$refs.childRef.value  // → ref 的值（Vue 3 Composition）
this.$refs.childRef.$el   // → 子组件的根 DOM 元素
this.$refs.childRef.focus() // → 调用子组件方法
