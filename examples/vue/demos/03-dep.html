📡 Dep 订阅者模式 — 响应式的核心

发布-订阅模式架构

响应式数据 state.count
↓ setter 触发
Dep.notify() — 通知所有订阅者
↓ 遍历 subs[]
Watcher.update() → 重新执行 render 函数
↓
DOM 更新完成

核心实现

class Dep {
  constructor() {
    this.subs = [];  // 订阅者列表
  }
  addSub(watcher) {
    this.subs.push(watcher);
  }
  notify() {
    // 通知所有订阅者
    this.subs.forEach(w => w.update());
  }
}
Dep.target = null;  // 当前正在计算的 Watcher

class Watcher {
  constructor(fn) {
    this.fn = fn;
    this.get();  // 执行时读取响应式属性，建立依赖
  }
  get() {
    Dep.target = this;
    this.fn();   // 读取 obj.count → get 陷阱 → dep.depend()
    Dep.target = null;
  }
  update() {
    this.get();  // 重新执行 → 视图更新
  }
}

依赖追踪流程

// 渲染 Watcher 执行 render()
new Watcher(() => {
  // 1. 读取 name  → nameDep.addSub(watcher)
  // 2. 读取 count → countDep.addSub(watcher)
  // 3. 读取 msg   → msgDep.addSub(watcher)
  return `${name} 你好，计数器：${count}，${msg}`;
});

// 任何响应式属性变化 → 对应 Dep.notify() → 触发 watcher.get()
// → 重新执行 render() → 生成新 VNode → diff → 更新 DOM
