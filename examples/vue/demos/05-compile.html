流程详解

// 1️⃣ parser(template) → AST
// 递归解析 HTML 标签，生成抽象语法树
// AST 节点: { type, tag, attrs, children }

// 2️⃣ transform(AST) → 优化
// Vue 3: 静态节点标记、静态提升

// 3️⃣ generate(AST) → 渲染函数字符串
// 输出: "with(this){return _c('div',...)}"
// _c = createElement (创建 VNode)
// _v = createTextVNode
// _s = toString

Vue 2 vs Vue 3 编译差异

特性Vue 2Vue 3
编译模式仅运行时常量构建时 + 运行时常量
静态提升❌ 无✅ hoistStatic
Patch Flag❌ 无✅ 动态节点标记
缓存事件❌ 无✅ cacheHandlers
Tree-shaking❌ 不支持✅ 支持
Fragment 多根❌ 需要额外标签✅ 原生支持

编译输出示例

// Vue 2 编译输出
with(this) {
  return _c(
    'div',
    { attrs: { "id": "app" } },
    [
      _c('h1', [_v(_s(title))]),
      _c('p', { class: status }, [_v(_s(message))]),
      _c('button', { on: { click: handleClick } }, [_v("点击")]),
      _l((list), (item) =>
        _c('li', { key: item.id }, [_v(_s(item.name))])
      )
    ]
  )
}
// _c = createElement  _v = createTextVNode
// _s = toString  _l = renderList
