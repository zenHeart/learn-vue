🌲 虚拟 DOM — VNode 结构与渲染

为什么需要虚拟 DOM？

  • ✅ 减少直接 DOM 操作 — 批量构建后再一次性操作真实 DOM
  • ✅ 跨平台能力 — 同一 VNode 可渲染到 Web/Weex/SSR/Canvas
  • ✅ 可追溯 — VNode 是纯 JS 对象，便于调试和比较

VNode 结构

const vnode = {
  type: 'div',       // 标签名
  props: {             // 属性（包含事件）
    id: 'app',
    class: 'container',
    onClick: handler
  },
  children: [           // 子节点数组
    { type: 'span', props: null, children: 'hello' },
    { type: 'p', props: { className: 'text' }, children: 'world' }
  ],
  key: 'unique-key',   // diff 优化：同层唯一标识
  el: null             // 指向真实 DOM（mount 后填充）
};

渲染函数 h() 实现

// h('div', props, children)
function h(type, props, children) {
  return {
    vtype: type,
    props: props || {},
    children: Array.isArray(children)
      ? children.map(c => typeof c === 'string' ? h('text', null, c) : c)
      : children
        ? [typeof children === 'string' ? h('text', null, children) : children]
        : []
  };
}
