🔀 Diff 算法 — 最小化 DOM 更新

核心原则：同层比较

// Vue 的 Diff 永远只比较同层节点，不跨层移动

旧 VNode          新 VNode
   div                 div
  / | \               / | \
 a  b  c             a  d  b

// 比较策略：
// 1. a → a (相同，复用)
// 2. b → b (相同，复用，但位置变了)
// 3. c → (空) (删除 c)
// 4. (空) → d (创建 d)

Vue 2: 双端比较（O(n)）

// 同时从新旧 children 的两端向中间遍历

旧: [A, B, C, D, E]
新: [A, B, F, C, D]

// 1. oldStart vs newStart → A vs A，命中
// 2. oldEnd vs newEnd   → E vs D，不匹配
// 3. oldEnd vs newStart → E vs F，不匹配
// 4. oldStart vs newEnd → A vs D，不匹配
// 5. 移动/创建/删除 ...

Vue 3: 最长递增子序列（O(n)）

// 核心思想：找到最长递增子序列，最小化移动

旧 children:  [A, B, C, D, E]  (索引: 0,1,2,3,4)
新 children:  [A, D, B, C, E]  (D在索引3,B在索引1,C在索引2,E在索引4)

Step 1: 建立 newIndex → oldIndex 映射
  newIndex 0 → oldIndex 0  (A)
  newIndex 1 → oldIndex 3  (D)
  newIndex 2 → oldIndex 1  (B)
  newIndex 3 → oldIndex 2  (C)
  newIndex 4 → oldIndex 4  (E)

Step 2: 求最长递增子序列 → [0, 2, 4] = [A, C, E]
  这三个节点不需要移动

Step 3: 只需移动 D、B 到正确位置
