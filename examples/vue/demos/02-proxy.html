⚡ Vue 3 响应式原理 — Proxy

核心原理

// Proxy 代理整个对象，而非一个个属性
const proxy = new Proxy(obj, {
  get(target, key, receiver) {
    // track(target, key) → 收集依赖
    const res = Reflect.get(target, key, receiver);
    // 懒代理：如果是对象，继续递归代理
    return isObject(res) ? reactive(res) : res;
  },
  set(target, key, value, receiver) {
    const old = target[key];
    const res = Reflect.set(target, key, value, receiver);
    // trigger(target, key) → 触发更新
    if (old !== value) trigger(target, key);
    return res;
  },
  deleteProperty(target, key) { /* 可检测到 delete */ },
  has(target, key) { /* 可检测到 in */ }
});

Proxy vs defineProperty 对比

✅ Proxy 的优势：
  • 只需代理一次，无需遍历所有属性（懒代理）
  • 支持检测 in 操作符
  • 支持检测对象新增属性
  • 支持检测对象删除属性
  • 支持数组下标变化检测
  • 支持 Map/Set/WeakMap/WeakSet

function effect(fn) {
  // 包装函数，自动追踪所有读操作
  const runner = () => {
    activeEffect = fn;
    fn();  // 执行时读取属性，触发 proxy getter → track
    activeEffect = null;
  };
  runner();
  return runner;
}

// 读取 proxy.count → track(target, 'count', activeEffect)
// 设置 proxy.count → trigger(target, 'count')
