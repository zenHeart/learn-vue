🌿 Vue 2 响应式原理 — Object.defineProperty

核心原理

// 在 get 中收集依赖，在 set 中触发通知
Object.defineProperty(obj, 'count', {
  get() {
    // 依赖收集：将当前 Watcher 记录到 dep.subs
    dep.depend();
    return val;
  },
  set(newVal) {
    if (val === newVal) return;
    val = newVal;
    // 通知所有依赖的 Watcher 更新
    dep.notify();
  }
});

defineProperty 的局限

  
    
    
  • ❌ 新增属性：直接 `obj.newKey = val` 不会触发响应式（需要 Vue.set）
    • 
    
  • ❌ 删除属性：`delete obj.key` 不会触发更新（需要 Vue.delete）
    • 
    
  • ❌ 数组下标：`arr[0] = x` 在 Vue 2 中默认不触发（通过 Vue.set）
    • 
    
  • ✅ Vue 3 Proxy 解决了以上所有问题
