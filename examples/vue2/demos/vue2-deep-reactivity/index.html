🌿 Vue2 深层对象修改与数组更新检测

1. 数组更新检测 — 索引直接修改

❌ 错误方式：直接索引赋值

items[0] = 'x' — 不会触发响应式更新
未更新
a b c 
// ❌ 不响应
items[0] = 'x'
render() // 视图未更新

✅ 正确方式：splice / Vue.set

items.splice(0, 1, 'x') — 触发更新
未更新
a b c 
// ✅ 响应
Vue.set(items, 0, 'x')
// 或
items.splice(0, 1, 'x')

2. 对象属性增删 — $set / $delete

❌ 错误方式：直接赋值新增属性

user.newProp = value — 不触发响应
{ name: "Alice" }
// ❌ 不响应
user.age = 18
render() // 视图未更新

✅ 正确方式：this.$set

this.$set(user, 'age', 18) — 触发更新
{ name: "Alice" }
// ✅ 响应
this.$set(user, 'age', 18)
render() // 视图立即更新

3. 深层嵌套对象 — 整体替换

深层新增属性 — 整体替换 vs 直接赋值

profile.address.city = 'Beijing' — 深层新增属性不响应（Object.defineProperty 只能监听已有属性）
{ name: "Alice" }
