混入
====

**讲解混入的使用及最佳实践**

-----

## 概述
混入使用如下情形.
* 多个组件存在相同的初始片段,利用混入进行公用

## 基本入门
1. 定义一个混入对象 [mixin.js](mixin.js)
2. 在组件中使用 [mixins](https://cn.vuejs.org/v2/api/#mixins) 载入混入对象
3. 此时组件可以正常使用混入方法

## 选项合并
当定义的混入对象和组件自定义重复时,会执行如下操作.
* 同名钩子,会将回调并入数组都会执行,执行顺序混入对象先执行
* 同名 data,会采用组件中的 data,其他不相同字段会合并
    > **只支持一层浅复制**
* 同名 methods,components,directives 混入规则和 data 类似
