    🧩 组件系统

    组件是 Vue 的核心构建块，封装可复用的视图和逻辑

    组件通信方式

    方式 方向 说明
    Props 父→子 父组件向子组件传递数据
    $emit 子→父 子组件向父组件发送事件
    Provide/Inject 跨级 祖先向后代传值
    Vuex/Pinia 全局 全局状态管理

    Props 向下传递事件流：

    父组件
    →
    Props
    数据
    →
    子组件

    组件示例

    // 定义组件 const ChildComponent = { props: { title: String, count: Number }, emits: ['update'], setup(props, { emit }) { const handleClick = () => { emit('update', props.count + 1); }; return { handleClick }; }, // template: ... }; // 使用组件 const ParentComponent = { setup() { const value = ref(0); return { value }; }, // template: <ChildComponent :count="value" @update="v => value = v" /> };

    ⚡ Vue 2 vs Vue 3

    Vue 3 在性能、TypeScript 支持、响应式原理等方面有显著提升

    特性 Vue 2 Vue 3
    响应式原理 Object.defineProperty Proxy (更强大)
    组件定义 Options API Composition API
    虚拟 DOM Snabbdom 优化过的 VNode
    TypeScript 部分支持 完整支持
    打包体积 ~33KB ~22KB (Tree-shaking)
    性能 Good Better (快 2-3x)
    API 风格 Options API Options + Composition
