2. 递归组件原理

核心思想：组件模板中使用自身来渲染子节点，当子节点没有 children 时递归自动终止。
// 关键：组件在模板中引用自身
template
  div.tree-node
    span.expand-icon @click="toggle" ▶
    span.label {{ node.label }}
    // 递归调用自身渲染子节点
    TreeNode
      v-for="child in node.children"
      :key="child.id"
      :node="child"
      :depth="depth + 1"
递归终止条件：当节点没有 children 或 children.length === 0 时，v-for 不会渲染任何内容，递归自动终止。

TreeNode 组件实现

const TreeNode = {
  name: 'TreeNode',
  props: {
    node: Object,
    depth: { type: Number, default: 0 }
  },
  emits: ['toggle', 'check'],
  setup(props, { emit }) {
    const isExpanded = ref(false)
    const hasChildren = computed(() =>
      props.node.children && props.node.children.length > 0
    )
    const toggle = () => {
      if (hasChildren.value) {
        isExpanded.value = !isExpanded.value
        emit('toggle', props.node)
      }
    }
    return { isExpanded, hasChildren, toggle }
  }
}

TreeStore 数据结构

核心设计：将树的状态管理（TreeStore）与视图渲染（TreeNode 组件）分离。

核心结构

class TreeStore { nodes: Map<id, node> // id -> 节点映射 childrenMap: Map<id, children[]> // 父id -> 子节点数组 expandedSet: Set<string> // 已展开节点 ID checkedSet: Set<string> // 已选中节点 ID }

节点数据结构

{ "id": "node-1", "label": "根节点", "children": [...], "expanded": false, "checked": false, "indeterminate": false, "isLeaf": false }

核心方法

class TreeStore {
  constructor(options = {}) {
    this.nodes = new Map()
    this.expandedSet = new Set(options.defaultExpandedKeys || [])
    this.checkedSet = new Set(options.defaultCheckedKeys || [])
  }
  registerNode(node) {
    this.nodes.set(node.id, { ...node,
      expanded: this.expandedSet.has(node.id),
      checked: this.checkedSet.has(node.id)
    })
  }
  setExpanded(nodeId, expanded) {
    expanded ? this.expandedSet.add(nodeId) : this.expandedSet.delete(nodeId)
    const node = this.nodes.get(nodeId)
    if (node) node.expanded = expanded
  }
  isExpanded(nodeId) { return this.expandedSet.has(nodeId) }
}

父子节点关系查询

getParent(nodeId) {
  for (const [pid, children] of this.childrenMap) {
    if (children.some(c => c.id === nodeId)) return this.nodes.get(pid)
  }
  return null
}
getAncestors(nodeId) {
  const ancestors = []
  let current = this.getParent(nodeId)
  while (current) { ancestors.unshift(current); current = this.getParent(current.id) }
  return ancestors
}

el-tree 核心源码分析

el-tree 核心设计是 TreeStore 数据管理与 el-tree-node 递归渲染的分离。

组件结构

el-tree ├── TreeStore (数据管理层) │ ├── nodes (所有节点 Map) │ ├── expandedSet (展开状态集合) │ └── checkedSet (选中状态集合) └── el-tree-node (递归渲染组件) ├── expand-icon (展开图标) ├── node-content (节点内容，含插槽) └── children (递归渲染子节点)

父子联动选择逻辑

handleCheck(node, checked) {
  this.setChecked(node.id, checked)
  const traverse = (n) => {
    n.childNodes?.forEach(c => { this.setChecked(c.id, checked); traverse(c) })
  }
  traverse(node)
  this.updateParentState(node)
}
updateParentState(node) {
  const parent = this.getParent(node.id)
  if (!parent) return
  const checked = parent.childNodes.filter(c => c.checked).length
  const total = parent.childNodes.length
  if (checked === 0) this.setChecked(parent.id, false)
  else if (checked === total) this.setChecked(parent.id, true)
  else this.setChecked(parent.id, false, { indeterminate: true })
}

懒加载实现

handleExpandnode() {
  if (this.node.isLeaf) return
  if (this.node.expanded) { this.tree.store.setExpanded(this.node.id, false); return }
  if (!this.node.loaded && !this.node.loading) {
    this.node.loading = true
    this.lazyLoad(this.node, (data) => {
      this.node.loading = false; this.node.loaded = true
      this.node.childNodes = this.normalize(data)
      this.tree.store.setExpanded(this.node.id, true)
    })
  } else { this.tree.store.setExpanded(this.node.id, true) }
}

关键设计模式

数据与视图分离：TreeStore 管理所有状态，TreeNode 只负责渲染。
扁平化数据结构：内部将树形数据扁平化为 nodes Map，便于 O(1) 查找节点。
事件冒泡设计：子节点通过 emit 向上发送事件，符合单向数据流。
