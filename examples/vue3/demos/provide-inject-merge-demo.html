Vue provide/inject merge 行为演示

场景：多层组件 provide 同一个 key

🧔 Root 组件
provide('config', { a: 1, b: 2, source: 'root' })
👦 Child 组件
provide('config', { b: 3, c: 4, source: 'child' })
⚠️ 注意：这里会覆盖（override）而非合并（merge）
👶 Grandchild 组件（inject）
实际注入结果： 
{{ JSON.stringify(injectedConfig, null, 2) }}
❌ 丢失了 { a: 1 }，因为子组件的 provide 完全覆盖了父级的
// Vue 源码简化逻辑（Vue 3） function provide(key, value) { let provides = currentInstance.provides // 关键：如果有父级 provides，基于它创建原型链 const parentProvides = currentInstance.parent?.provides if (parentProvides) { provides = Object.create(parentProvides) // 创建原型链 } // 直接赋值 = 覆盖，而非合并 provides[key] = value } // 查找时使用原型链 function inject(key) { let provides = currentInstance.provides // 沿着原型链向上找，找到最近的定义 while (!(key in provides)) { provides = Object.getPrototypeOf(provides) } return provides[key] }

方法一：在 provide 时手动合并

// Child.vue import { inject, provide } from 'vue' export default { setup() { // 1. 先注入父级的 config const parentConfig = inject('config', {}) // 2. 手动合并：父级展开 + 子级覆盖 const mergedConfig = { ...parentConfig, // 保留父级的 a: 1 b: 3, // 子级覆盖 b c: 4 // 子级新增 c } // 3. provide 合并后的结果 provide('config', mergedConfig) } }
✅ 合并后的正确结果：

方法二：使用 reactive 对象（推荐）

使用 reactive 对象传递，所有组件共享同一个引用，修改会自动同步：

// Root.vue import { provide, reactive } from 'vue' setup() { const globalState = reactive({ user: { name: 'Alice', theme: 'light' }, count: 0 }) provide('globalState', globalState) } // Child.vue（任意层级） import { inject } from 'vue' setup() { const globalState = inject('globalState') // 直接修改，所有 inject 的组件都会响应 globalState.count++ globalState.user.theme = 'dark' }

核心结论

行为 是否支持 说明
自动合并（merge） ❌ 不支持 子组件 provide 完全覆盖父组件的同名 key
原型链查找 ✅ 支持 inject 沿着原型链向上找，找不到才用默认值
响应式传递 ✅ 支持 使用 reactive/ref 包装的值保持响应
手动合并 ✅ 支持 在 provide 时手动 merge 父级和子级的值

选择建议

场景 推荐方案
全局共享配置 reactive 对象
多层组件局部覆盖 手动合并
主题/语言切换 reactive 单例
插件默认配置 手动 merge + defaultsDeep
💡 最佳实践：
  1. 优先使用 reactive 对象传递响应式状态
  2. 如需覆盖，使用手动合并：{ ...parent, ...child }
  3. 避免深层嵌套的 provide 链，保持数据流清晰
