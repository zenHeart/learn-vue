Vue 3 v-model 在 Render 函数中的使用

v-model 工作原理

v-model="value"
=
:modelValue + @update:modelValue

Template vs Render 函数对比

// Template 中使用 v-model <input v-model="inputValue" /> // 编译器自动转换为： <input :modelValue="inputValue" @update:modelValue="inputValue = $event" />
import { h } from 'vue'; render() { return h('input', { value: this.modelValue, onInput: (e) => this.$emit('update:modelValue', e.target.value) }); }
// JSX 中使用 v-model <input value={this.modelValue} onInput={(e) => this.$emit('update:modelValue', e.target.value)} />
关键点：
  • modelValue - v-model 绑定的属性名（Vue 3）
  • update:modelValue - 更新值的事件名
  • value + onInput - 实际 DOM 元素的绑定

Vue 2 vs Vue 3 对比

特性 Vue 2 Vue 3
v-model 属性 value modelValue
v-model 事件 input update:modelValue
Render 函数 createElement() h()
多个 v-model 需要插件 原生支持 v-model:xxx

Vue 2 示例

export default { props: ['value'], render(createElement) { return createElement('input', { domProps: { value: this.value }, on: { input: (e) => this.$emit('input', e.target.value) } }); } };

Render 函数实现的 Input（模拟）

这里使用 Vue 的响应式系统模拟 render 函数的行为。真实 render 函数中， 需要通过 props 接收 modelValue，通过 emit 发送 update:modelValue 事件。

代码实现

// RenderInput.vue - script setup <script setup> import { h } from 'vue' const props = defineProps({ modelValue: { type: String, default: '' } }) const emit = defineEmits(['update:modelValue']) // 直接 return render 函数 return () => h('input', { value: props.modelValue, onInput: (e) => emit('update:modelValue', e.target.value) }) </script>
// RenderInput.vue - Options API export default { props: { modelValue: { type: String, default: '' } }, emits: ['update:modelValue'], render() { return h('input', { value: this.modelValue, onInput: (e) => this.$emit('update:modelValue', e.target.value) }) } }
// render 函数核心逻辑 render() { return h('input', { // 1. 绑定 value 为 modelValue value: this.modelValue, // 2. 监听 input 事件 onInput: (e) => { // 3. 发射 update:modelValue 事件 this.$emit('update:modelValue', e.target.value) } }) }

v-model 修饰符处理

.lazy 修饰符

使用 onChange 替代 onInput，失焦后才更新

// onChange: 失焦时才触发（相当于 .lazy） onChange: (e) => emit('update:modelValue', e.target.value)

.trim 修饰符

自动去除首尾空格

onInput: (e) => { const value = e.target.value.trim() emit('update:modelValue', value) }

.number 修饰符

自动转换为你 number 类型

onInput: (e) => { const parsed = parseFloat(e.target.value) const value = isNaN(parsed) ? e.target.value : parsed emit('update:modelValue', value) }

练习 1: Render 函数实现 Counter

任务：

在 render 函数中实现一个 Counter 组件，接收 modelValue 作为计数初始值，emit update:modelValue 事件更新值。

点击 +1 按钮，计数加 1；点击 -1 按钮，计数减 1。

// 补全以下代码
render() { return [ h('span', {}, '计数: ' + this.modelValue), h('button', { onClick: () => { // 发射 update:modelValue 事件，加 1 }}, '+1'), h('button', { onClick: () => { // 发射 update:modelValue 事件，减 1 }}, '-1') ] }
答案： 
render() {
  return [
    h('span', {}, '计数: ' + this.modelValue),
    h('button', { onClick: () => this.$emit('update:modelValue', this.modelValue + 1) }, '+1'),
    h('button', { onClick: () => this.$emit('update:modelValue', this.modelValue - 1) }, '-1')
  ]
}
