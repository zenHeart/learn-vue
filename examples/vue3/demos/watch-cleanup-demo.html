Vue 3 Watch 内存泄漏与清理

本演示展示 Vue 3 Composition API 中 watch 的触发机制、清理机制以及内存泄漏问题的解决方法。

1. watch vs watchEffect 初始执行时机

watch 默认不执行（immediate: false），watchEffect 默认立即执行。

2. flush 选项的影响

pre: 组件更新前触发（默认）
post: 组件更新后触发（用于访问更新后的 DOM）
sync: 同步触发（不推荐）

value = {{ flushValue }}
选择 flush 类型并点击按钮测试

知识点总结

特性 说明
watch 默认不执行 需要设置 immediate: true 才会在创建时执行
watchEffect 立即执行 默认在创建时立即执行，可使用 flush: 'post' 延迟
onWatcherCleanup Vue 3.5+ 推荐使用，在 watch 重新运行前或组件卸载时调用
stop() 函数 watch 返回的停止函数，可手动调用停止监听
flush: 'pre' 组件更新前触发（默认）
flush: 'post' 组件更新后触发，用于访问更新后的 DOM
flush: 'sync' 同步触发，不推荐使用（性能问题）
