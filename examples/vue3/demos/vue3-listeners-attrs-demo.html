📦 $attrs 在 Vue 3 中的结构

// 当父组件传递这些属性和事件时： <MyComponent id="input-field" placeholder="Enter text" :value="modelValue" @input="handleInput" @focus="handleFocus" @blur="handleBlur" /> // 子组件接收到的 $attrs： { id: 'input-field', placeholder: 'Enter text', value: 'initial', onInput: [Function: handleInput], onFocus: [Function: handleFocus], onBlur: [Function: handleBlur] } // 注意：事件监听器以 'on' + 大写事件名 的格式存在

🔍 事件 vs 属性 区分

function analyzeAttrs(attrs) { const { // 分离普通属性 ...props } = attrs // 提取事件监听器（以 on 开头的键） const events = Object.fromEntries( Object.entries(attrs) .filter(([key]) => key.startsWith('on')) .map(([key, value]) => [key.slice(2).toLowerCase(), value]) ) return { props, events } }

🎛️ inheritAttrs 控制

默认行为：所有 $attrs 属性会渲染到根元素上

禁用后：可以使用 v-bind="$attrs" 手动控制属性分发

// 禁用 inheritAttrs <script setup> defineOptions({ inheritAttrs: false // 禁用自动继承 }) </script> <template> <div> <!-- 只将 class 和 style 传递给根元素 --> <input v-bind="$attrs" class="custom-input" /> </div> </template>
场景 写法
根元素继承所有 attrs 默认行为，无需额外代码
禁用继承 defineOptions({ inheritAttrs: false })
手动分发到特定元素 v-bind="$attrs" on any element
排除特定属性 解构或过滤后使用

📌 核心要点总结

  • $listeners 已移除：Vue 3 将事件监听器合并到 $attrs 中
  • 事件命名变化：@click → onClick（在 $attrs 中）
  • 传递简化：只需 v-bind="$attrs" 即可同时传递属性和事件
  • 不再需要 v-on="$listeners"：已合并到 v-bind="$attrs"
  • inheritAttrs：行为不变，仍用于控制根元素继承
