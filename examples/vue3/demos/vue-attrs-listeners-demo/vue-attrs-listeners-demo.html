$attrs 包含什么？

<!-- 父组件 --> <MyButton type="primary" ← 在 props 中声明 → 不在 $attrs class="custom-btn" ← 不在 props 中 → 在 $attrs @click="handleClick" ← 事件 → 在 $attrs 中（Vue3） data-id="123" ← 自定义属性 → 在 $attrs />

图解数据流

父组件传递:
type="primary" | class="custom" | @click="handle" | data-id="123" | id="btn"

子组件声明 props: ['type']

结果:
✓ type → 被 props 接收，不在 $attrs 中
✓ class="custom" → 在 $attrs 中，会自动透传给根元素
✓ @click="handle" → 在 $attrs.onClick 中（Vue3）
✓ data-id="123" → 在 $attrs 中
✓ id="btn" → 在 $attrs 中

$attrs 详解

Vue 3 中的 $attrs 结构

// Vue 3 $attrs 包含： { // 透传的属性（不在 props 中声明） class: 'custom-btn large', style: { color: 'red' }, id: 'my-btn', 'data-id': '123', // 透传的事件监听器（Vue3 中） onClick: function() { /* ... */ }, onFocus: function() { /* ... */ }, onInput: function() { /* ... */ } }

setup 中使用

// 组合式 API import { useAttrs } from 'vue' setup(props, { attrs }) { // 方式一：参数获取 console.log(attrs.class) console.log(attrs.onClick) // 方式二：useAttrs() const attrs = useAttrs() }

inheritAttrs 行为

配置行为
inheritAttrs: true（默认）未声明的 attrs 自动应用到根元素
inheritAttrs: false不自动应用，需手动 v-bind="$attrs"

Button 组件示例

演示 $attrs 如何透传给内部元素：

组件结构（伪代码）：

// Button.vue - 子组件 <template> <button v-bind="$attrs" class="my-btn"> <slot /> </button> </template> <script setup> // 不需要声明 type、class、onClick 等 // 它们会自动从 $attrs 透传到 button 元素 </script>

使用示例：

检测父组件是否传递了特定属性

const attrs = useAttrs() // 检测是否传递了 href（智能组件） const isLink = computed(() => !!attrs.href) // 检测是否有 click 事件 const hasClick = computed(() => 'onClick' in attrs)

Input 组件示例

演示 v-model 和 $attrs 的配合：

表单输入组件（透传所有属性）：

// FormInput.vue <template> <div class="form-field"> <label v-if="label">{{ label }}</label> <input v-bind="$attrs" class="my-input" /> </div> </template> <script setup> defineProps(['label']) // 只声明 label </script>

检测父组件监听器

方法一：检查 $attrs 中的事件属性

// Vue 3 const attrs = useAttrs() const hasClick = computed(() => 'onClick' in attrs) const hasFocusHandlers = computed(() => 'onFocus' in attrs && 'onBlur' in attrs )

方法二：警告缺失事件

watch(() => attrs['onClick'], (handler) => { if (!handler) { console.warn(`[MyButton] 建议提供 click 事件处理器`) } }, { immediate: true })
