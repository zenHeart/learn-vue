什么是 Vue 3 Migration Build

Vue 3 提供了一个特殊的迁移构建版本（@vue/compat），在 Vue 3 上提供可配置的 Vue 2 兼容行为，让你可以在迁移过程中逐步处理问题。

三种兼容模式

模式配置值说明
Vue 2 模式'vue2'完全模拟 Vue 2 行为（默认）
Vue 3 模式'vue3'完全使用 Vue 3 行为
配置模式'conf'每个特性单独配置

兼容层工作原理

// Vue 2 API
import Vue from 'vue'
Vue.filter('myFilter', fn)  // → 自动转为全局 mixin

// @vue/compat 内部映射
Vue.filter()  // → app.config.globalProperties.$filters
Vue.component()  // → app.component()
vm.$watch()  // → 自动映射到 Vue 3 watch()

逐特性兼容配置

// vite.config.js
vue({
  template: {
    compatConfig: {
      MODE: 2,  // 全部兼容模式
      
      // 或者逐特性配置
      INSTANCE_EVENT_EMITTER: false,  // 关闭 $on/$off 兼容
      FEATURE_OPTIONS_API: false,  // 关闭选项 API
      FEATURE_TELEPORT: false   // 关闭 Teleport 警告
    }
  }
})

安装

npm install vue@3 @vue/compat@3 --save
# 或
yarn add vue@3 @vue/compat@3

Vite 配置

// vite.config.js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [
    vue({
      template: {
        compatConfig: {
          MODE: 2  // Vue 2 兼容模式
        }
      }
    })
  ],
  resolve: {
    alias: {
      'vue': '@vue/compat'  // 替换为兼容版本
    }
  }
})

Vue CLI / Webpack 配置

// vue.config.js (Vue CLI)
module.exports = {
  chainWebpack: config => {
    config.resolve.alias.set('vue$', '@vue/compat')
  }
}

// webpack.config.js
module.exports = {
  resolve: {
    alias: {
      'vue$'`: '@vue/compat'
    }
  }
}

步骤二：处理全局 API

Vue 2 → Vue 3 全局 API 变化
Vue 2Vue 3

Vue.filter()已移除，用 app.config.globalProperties
Vue.mixin()已移除，用 composable
Vue.directive()app.directive()
Vue.prototypeapp.config.globalProperties
beforeDestroybeforeUnmount
destroyedunmounted

步骤三：选项 API → 组合式 API

// Vue 2 选项式
export default {
  data() { return { count: 0 } },
  computed: {
    double() { return this.count * 2 }
  },
  methods: {
    increment() { this.count++ }
  }
}

// Vue 3 组合式（推荐目标）
import { ref, computed } from 'vue'
export default {
  setup() {
    const count = ref(0)
    const double = computed(() => count.value * 2)
    const increment = () => count.value++
    return { count, double, increment }
  }
}
