递归组件核心概念

什么是递归组件？

递归组件是指在组件的模板中调用自身的组件。

// TreeNode.vue - 递归调用自身 <template> <div class="tree-node"> <div>{{ node.label }}</div> <!-- 递归调用 --> <TreeNode v-for="child in node.children" :key="child.id" :node="child" /> </div> </template> export default { name: 'TreeNode' // ← 必须有 name 才能递归 }

递归组件的必要条件

条件说明
组件必须有 name组件模板中引用自身需要通过 name
必须有终止条件否则无限递归导致栈溢出
数据必须能收敛子节点数量/深度有限

数据传递方式

方式适用场景
Props 逐层传递层级不深（< 3层）
provide/inject层级较深，避免逐层透传
事件向上传递子组件需要通知父组件
Pinia/Vuex复杂状态管理

最佳实践

1. 必须设置终止条件

// ❌ 错误：没有终止条件 <TreeNode :node="node.child" /> // ✅ 正确：检查终止条件 <TreeNode v-if="node.children?.length" :node="node.children[0]" />

2. 设置最大深度限制

props: { maxDepth: { type: Number, default: 10 } // 防止栈溢出 } watch(() => props.depth, (newDepth) => { if (newDepth >= props.maxDepth) { console.warn(`超过最大深度 ${props.maxDepth}`) } })

3. 使用唯一 key

// 必须提供唯一的 :key <TreeNode v-for="child in node.children" :key="child.id" // ← 必须 :node="child" />

4. provide/inject 跨层级传值

// 祖先组件 provide provide('tree', { selectedId: ref(null), expandedIds: ref(new Set()), selectNode: (id) => selectedId.value = id }) // 后代组件 inject const { selectedId, expandedIds, selectNode } = inject('tree')

5. 处理循环引用

// 数据可能出现 A → B → A 循环 computed: { safeChildren() { return this.node.children?.filter( child => !this.visitedIds.includes(child.id) ) || [] } }
