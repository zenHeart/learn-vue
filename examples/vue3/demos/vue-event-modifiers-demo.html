Vue 事件修饰符详解

深入理解 .capture / .stop / .prevent / .native 等修饰符的实现原理

事件传播三阶段
DOM 事件传播分为三个阶段：捕获阶段 → 目标阶段 → 冒泡阶段 
┌─────────────────────────────────────────────────────────────┐
│                    事件传播三阶段                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   1. 捕获阶段 (Capture Phase)                               │
│      Window → Document → HTML → Body → ... → Target        │
│                                                             │
│   2. 目标阶段 (Target Phase)                                │
│      事件到达目标元素本身                                     │
│                                                             │
│   3. 冒泡阶段 (Bubble Phase)                                │
│      Target → ... → Body → HTML → Document → Window        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
💡 关键点
默认情况下，addEventListener 在 bubble phase 触发。 设置 useCapture: true 可在 capture phase 触发。
JavaScript 事件监听示例
// 冒泡阶段触发（默认）
element.addEventListener('click', handler, false);

// 捕获阶段触发
element.addEventListener('click', handler, true);

点击子元素，观察两种模式的执行顺序差异：

未使用 .capture 子元素 → 父元素（冒泡）

（因为使用了 .stop）
✅ 有 .capture

子元素（无修饰符）

常用修饰符一览
修饰符 等价代码 作用
.stop event.stopPropagation() 阻止事件冒泡
.prevent event.preventDefault() 阻止默认行为
.capture useCapture: true 捕获阶段触发
.self event.target === event.currentTarget 仅自身为目标时触发
.once 一次性监听器 事件只触发一次
.passive 滚动优化 提升滚动性能
.stop vs .self 区别
.stop 阻止事件传播到父元素，而 .self 仅在 event.target 是自身时才触发。
场景 .stop .self
点击子元素 父元素 handler 不触发 父元素 handler 不触发
点击父元素自身 父元素 handler 触发 父元素 handler 触发
点击父元素背景 父元素 handler 触发 父元素 handler 触发
.native 修饰符（Vue 2 特有）
在 Vue 2 中，自定义组件默认不触发原生事件。使用 .native 可以监听组件根元素的原生事件。
⚠️ 注意
Vue 3 已移除 .native 修饰符！在 Vue 3 中，非 props 的 attributes 会自动继承到组件根元素，无需使用 .native。
Vue 2 代码示例
<!-- MyButton.vue -->
<template>
  <button @click="handleClick">
    <slot></slot>
  </button>
</template>

<!-- Parent.vue (Vue 2) -->
<template>
  <!-- 使用 .native 监听根元素的原生 click -->
  <MyButton @click.native="handleNativeClick">
    点击我
  </MyButton>
</template>
Vue 3 替代方案
<!-- Vue 3: 直接监听即可，无需 .native -->
<template>
  <MyButton @click="handleClick">
    点击我
  </MyButton>
</template>

<!-- 或使用 $attrs 显式传递 -->
<template>
  <button v-bind="$attrs">
    <slot></slot>
  </button>
</template>

<script setup>
defineOptions({ inheritAttrs: false })
</script>
Vue 2 vs Vue 3 对比
特性 Vue 2 Vue 3
.native 支持 已移除
组件事件继承 需要 .native 通过 $attrs 自动
emits 选项 无 支持，推荐使用
inheritAttrs 默认 true 可设置为 false
自测题
1. 点击使用 @click.capture 的父元素内的子元素，执行顺序是？
A. 子元素 → 父元素
B. 父元素 → 子元素
C. 只有父元素触发
✅ 正确！.capture 在捕获阶段触发，所以父元素先于子元素。 ❌ 错误。正确答案：B。使用 .capture 后，父元素在捕获阶段先触发。
2. Vue 3 中，以下哪种方式可以监听子组件根元素的原生 click？
A. <Child @click.native="handler">
B. <Child @click="handler">
C. 必须使用 v-on 指令
✅ 正确！Vue 3 自动将事件传递到根元素，不需要 .native。 ❌ 错误。正确答案：B。Vue 3 中 .native 已被移除，直接使用 @click 即可。
3. .stop 和 .self 的主要区别是？
A. 没有区别
B. .stop 阻止自身触发，.self 阻止冒泡
C. .stop 阻止冒泡传播，.self 仅在 target 是自身时触发
✅ 正确！.stop 调用 stopPropagation()，.self 检查 event.target。 ❌ 错误。正确答案：C。
