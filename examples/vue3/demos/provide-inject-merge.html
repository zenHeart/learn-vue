场景二：手动合并策略

父组件提供
{ name: 'Alice', age: 30, city: 'Beijing' }
子组件使用 mergeProvider 合并 
function mergeProvider(key, newValue) {
  const parentValue = inject(key, {})
  const merged = { ...parentValue, ...newValue }
  provide(key, merged)
}
提供: { age: 25, gender: 'female' }
孙组件获取结果
{{ JSON.stringify(mergedResult) }}
合并成功：保留父级属性，新增子级属性
