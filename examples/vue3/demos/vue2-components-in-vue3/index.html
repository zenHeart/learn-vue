Vue2 组件在 Vue3 中使用

说明：本示例展示如何在 Vue3 应用中使用 Vue2 风格的组件。 实际生产环境需要使用 @vue/compat 构建版本。 这里使用纯 Vue3 模拟 Vue2 组件的行为。

示例 1: 按钮组件 (Options API)

主要按钮 次要按钮 成功按钮 危险按钮

点击次数: {{ clickCount }}

示例 2: 卡片组件 (带 Slot)

这是一个使用 Options API 编写的 Vue2 风格组件。

支持 slot 内容分发。

通过 props 传递数据：

  • title: 卡片标题
  • 内容通过 slot 传入

示例 3: 输入框组件 (v-model 双向绑定)

输入的数据：

用户名: {{ username || '(未输入)' }}

邮箱: {{ email || '(未输入)' }}

示例 4: 计数器组件 (父子通信)

当前计数: {{ displayCount }}

示例 5: 过滤器模拟 (Vue3 推荐用 methods 替代)

原始文本: {{ rawText }}

大写: {{ toUpper(rawText) }}

首字母大写: {{ capitalize(rawText) }}

反转: {{ reverse(rawText) }}

Vue3 变化：Filters 语法已被移除。 在 Vue3 中应使用 methods 或 computed 替代。
