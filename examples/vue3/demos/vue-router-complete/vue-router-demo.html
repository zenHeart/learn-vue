动态路由与参数

路由参数

使用 :paramName 语法定义动态路由参数。

// 定义动态路由 { path: '/user/:id', component: User } { path: '/article/:category/:id', component: Article } // 获取参数 const route = useRoute() route.params.id // 获取 :id route.params.category // 获取 :category route.query.q // 获取 URL 查询参数

导航守卫

守卫类型

守卫说明
beforeEach全局前置守卫，路由切换前
beforeResolve全局解析守卫，确认前
afterEach全局后置守卫，切换后
beforeEnter路由独享守卫
beforeRouteEnter组件内守卫，渲染前
beforeRouteUpdate组件内守卫，参数变化
beforeRouteLeave组件内守卫，离开前

守卫参数

router.beforeEach((to, from, next) => { // to: 目标路由 // from: 当前路由 // next: 解析回调 if (to.meta.requiresAuth && !isLoggedIn) { next('/login') // 重定向 } else { next() // 确认导航 } })

路由元信息 (meta)

使用 meta 属性为路由附加自定义数据，如权限、标题等。

const routes = [ { path: '/admin', component: Admin, meta: { requiresAuth: true, role: 'admin' } }, { path: '/profile', component: Profile, meta: { title: '用户资料' } } ] // 访问 meta router.beforeEach((to, from, next) => { if (to.meta.requiresAuth && !isLoggedIn) { next('/login') } document.title = to.meta.title || '默认标题' next() })

常见 meta 用法

字段用途
requiresAuth是否需要登录
role权限角色
title页面标题
keepAlive是否缓存组件
breadcrumb面包屑数据
