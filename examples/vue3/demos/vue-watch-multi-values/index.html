常见问题解答

Q: watch 回调函数中如何区分哪个值变了？

watch([a, b, c], ([newA, newB, newC], [oldA, oldB, oldC]) => {
  if (newA !== oldA) console.log('a changed')
  if (newB !== oldB) console.log('b changed')
})

Q: 如何取消 watch 监听？

const stop = watch(data, (newVal) => {
  if (newVal === 'complete') stop() // 取消监听
})
