⚠️ 问题现象

排序后，组件类型和内容出现错乱！
- 组件A 可能显示为 组件B 的样式
- 内部计数器状态被错误复用
- 这是因为使用了 index 作为 key

✅ 解决方案

方案一：条件渲染
根据组件类型使用条件渲染，完全避免动态组件。适合组件类型较少的情况。

方案二：唯一ID作为Key
使用 item.id 替代 index 作为 key，确保 Vue 能正确追踪每个元素。

方案三：Computed包装
使用 computed 的 get/set 包装排序逻辑，保持数据响应性。

方案四：过渡动画
在正确 key 的基础上添加 transition-group 动画，提升用户体验。
