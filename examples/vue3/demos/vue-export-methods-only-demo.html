Vue 组件只导出方法演示

核心结论

Vue 组件可以只导出方法而不导出样式。 样式始终是组件私有的。

defineExpose() 可暴露 样式无法暴露

为什么可以只导出方法？

Vue 组件的各个部分是解耦的：

  • 逻辑（script）：通过 defineExpose() 控制暴露内容
  • 模板（template）：仅在父组件中被渲染为子组件的视图
  • 样式（style）：始终 scoped，无法从外部访问

defineExpose() 就像一个"白名单"，只有列入其中的内容才对父组件可见。

完整示例

子组件 (Counter.vue)

<script setup>
import { ref } from 'vue'

const count = ref(0)

function increment() {
  count.value++
}

defineExpose({ increment }) // ✅ 只暴露方法
</script>

<template>
  <div class="my-style">{{ count }}</div> <!-- 样式私有 -->
</template>

<style scoped>
.my-style { color: red; } /* 父组件看不到 */
</style>

父组件使用

const counterRef = ref(null)
counterRef.value.increment() // ✅ 可以
counterRef.value.count        // ❌ 报错：未暴露

暴露内容对比

内容 能否暴露 样式暴露
data 可以 不暴露
methods 可以 不暴露
computed 可以 不暴露
内部样式 不可能 不暴露

小结

Vue 组件的样式通过 <style scoped> 实现完美隔离。父组件通过 ref 获取的只是组件暴露的 API（方法、数据），样式完全不受影响。

这是一个有意的设计决策，让组件可以同时包含复杂的内部样式和简洁的公共接口。
