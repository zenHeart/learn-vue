Vue 3 自定义渲染器 交互演示

什么是自定义渲染器？

Vue 3 的核心渲染引擎是平台无关的。通过自定义渲染器，你可以将 Vue 的响应式系统扩展到任何渲染目标。

标准 Vue vs 自定义渲染器

维度标准 Vue（Web）自定义渲染器
createElement创建 DOM 元素创建任意节点（Canvas、终端、Native）
insertDOM.appendChild()自定义插入逻辑
patchProp设置 DOM 属性设置任意属性（Canvas 样式、终端属性）
输出HTML 页面Canvas/WebGL/终端/图片/PDF...

createRenderer 基本结构

import { createRenderer } from 'vue' const { render, createApp } = createRenderer({ createElement(type) { // 创建节点 return { type, props: {}, children: [] } }, insert(child, parent, anchor) { // 插入节点 parent.children.push(child) child.parent = parent }, patchProp(node, key, prev, next) { // 更新属性 node.props[key] = next }, // ... 其他 API })

为什么需要自定义渲染器？

  • 在终端中渲染 Vue 组件（Ink 之于 React）
  • Canvas/WebGL 游戏或可视化
  • 跨平台 Native 应用
  • 服务端生成 PDF/图片
  • AR/VR 界面

createElement 详解

const nodeOps = { createElement(type, { style, class: cls, onClick, ...props }, children) { // type: 元素类型，如 'div', 'button', 'circle' // props: 属性对象（包含 style, class, 事件等） // children: 子节点数组 return { type, props: { style, class: cls, onClick, ...props }, children: children.flat(), el: null // 自定义渲染器自行管理 } } }

patchProp 详解

patchProp(node, key, prevValue, nextValue) { if (key === 'style') { // 处理行内样式 node.props.style = { ...node.props.style, ...nextValue } } else if (key === 'class') { // 处理 class node.props.class = nextValue } else if (key.startsWith('on')) { // 处理事件（如 onClick） node.props[key] = nextValue } else { // 其他属性 node.props[key] = nextValue } }

终端渲染器原理

// 终端渲染器核心概念 const nodeOps = { createElement(type, { style, onClick, ...props }, children) { return { type, props: { style, onClick, ...props }, children } }, insert(child, parent) { parent.children = parent.children || [] parent.children.push(child) child.parent = parent renderNode(child) // 渲染到终端 }, patchProp(node, key, _, nextValue) { node.props[key] = nextValue renderNode(node) // 重新渲染 } }

模拟 Vue 响应式系统在 Canvas 上渲染图形：

Canvas 渲染器核心概念

const nodeOps = { createElement(type) { return { type, props: {}, children: [] } }, insert(child, parent) { parent.children.push(child) child.parent = parent }, patchProp(node, key, _, nextValue) { node.props[key] = nextValue } } function renderTree(node, ctx) { switch(node.type) { case 'circle': ctx.beginPath() ctx.arc(node.props.cx, node.props.cy, node.props.r, 0, Math.PI * 2) ctx.fillStyle = node.props.fill || 'black' ctx.fill() break case 'rect': ctx.fillStyle = node.props.fill || 'black' ctx.fillRect(node.props.x, node.props.y, node.props.w, node.props.h) break } node.children.forEach(child => renderTree(child, ctx)) }

实际应用场景

1. 终端应用（Vue + CLI）

类似 React 的 Ink，Vue 可以渲染终端 UI：

// ink-vue 示例 import { render } from 'vue' import { createTerminalRenderer } from 'ink-vue' const Counter = { setup() { const { count, inc, dec } = useCounter() return () => h('div', {}, [ h('Box', {}, `Count: ${count.value}`), h('Button', { onClick: inc }, '+'), h('Button', { onClick: dec }, '-') ]) } }

2. Canvas/WebGL 可视化

将 Vue 响应式系统用于游戏或数据可视化：

  • 响应式绑定 Canvas 图形属性
  • computed 计算派生图形
  • watchEffect 监听变化自动重绘

3. PDF/图片生成

服务端使用 Vue 模板 + 自定义渲染器生成 PDF：

import { render } from 'vue' import { createPDFRenderer } from 'vue-to-pdf' const Invoice = { props: ['items'], /* ... */ } render(h(Invoice, { items }), pdfContext)

4. 跨平台 Native UI

结合 Native 渲染引擎（如 Skia、CoreGraphics），用 Vue 构建 Native 应用界面。
