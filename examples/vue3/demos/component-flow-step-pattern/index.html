🔀 组件流程步骤模式

将确认框等复杂组件设计为顺序流程的一个步骤

📚核心概念

Step Pattern

将完整流程拆分为多个独立步骤组件，每个步骤负责单一业务逻辑，通过统一接口与容器通信。

State Machine

用有限状态机管理流程状态转换，确保状态转换可预测，避免非法状态出现。

Flow Context

通过 provide/inject 跨组件传递流程上下文，包括当前步骤、共享数据、控制方法。

Compound Component

复合组件模式，通过插槽和上下文组合多个步骤，实现高度可复用的流程组件。
