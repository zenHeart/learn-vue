Vue 组件渲染调试演示

v-if vs v-show 行为对比

v-if（条件渲染）

v-if 显示
组件未渲染
<!-- v-if: false 时 DOM 完全不存在 --> <div v-if="showIf">v-if 显示</div> <!-- 检查 DOM: elements 中无此元素 -->

v-show（CSS 显示切换）

v-show 显示
元素仍存在于 DOM
<!-- v-show: 始终渲染，仅切换 display --> <div v-show="showShow">v-show 显示</div> <!-- 检查 DOM: elements 中存在，仅 display:none -->
调试提示：打开浏览器开发者工具 → Elements 面板，观察两种方式的 DOM 差异。

Props 传递问题演示

Props 正确传递

{{ correctProps || '无背景色' }}
// 子组件接收 props props: { color: { type: String, default: '' } } // 模板中使用 <div :style="{ background: color }">{{ }}</div>

Props 为 undefined

显示红色（默认值）
// 问题：传递 undefined 导致无背景色 <Child :color="undefinedProps" /> // 解决：使用可选链或默认值 <Child :color="props?.color || 'red'" />
常见问题：父组件数据未定义或为 null 时，子组件 props 收到 undefined/null，需提供默认值。

CSS visibility/opacity 隐藏

opacity: 0（透明但占位）

透明元素（仍占据空间）
元素已移除
.invisible { opacity: 0; /* 元素可见但透明 */ } 检查：DOM 存在，computed 显示 opacity:0

visibility: hidden（隐藏但占位）

visibility 隐藏
元素已移除
.hidden { visibility: hidden; /* 占据空间但不可见 */ } 检查：DOM 存在，computed 显示 visibility:hidden
调试提示：使用 Chrome DevTools → Elements → Computed 面板查看元素的最终样式。

响应式数据更新演示

ref 响应式数据

{{ count }}
// setup 中定义 ref const count = ref(0) // 模板中自动解包，直接使用 {{ count }} // 值变化 → 自动触发更新

reactive 对象

{{ state.count }}
// setup 中定义 reactive const state = reactive({ count: 0 }) // 模板中使用 state.count // 直接修改属性，保持响应式
常见问题：解构 reactive 对象会丢失响应性，应使用 `toRefs` 或在模板中直接访问。
