--- tags: [learn] --- v-for 动态插槽排序异常演示

v-for 中使用动态插槽排序显示异常

交互式演示

  • {{ items.indexOf(item) + 1 }} ID:{{ item.id }} {{ item.slotType }} {{ item.content }} 排序值: {{ item.order }}
观察：点击排序按钮后，列表顺序改变，但每项的 ID、类型标签、内容是否正确对应？ 如果出现错位，说明存在「排序后显示异常」问题。

为什么排序后显示异常？

核心问题：v-for 渲染列表时，如果使用了动态插槽（v-slot:[name]）， 当列表排序后，插槽内容可能与列表项不匹配。

常见原因

原因说明后果
key 绑定错误 key 放在子组件上，而非插槽根元素 Vue 无法正确追踪列表项
直接修改数组 .sort() 修改原数组但不触发更新 视图不更新
动态插槽名晚于内容渲染 slotName 变化时内容未同步更新 显示错误的插槽内容
排序动画与动态插槽冲突 <transition-group> 管理动画时插槽变化 动画错乱

问题代码示例

<!-- ❌ 错误示例 -->
<div v-for="item in sortedItems" :key="item.id">
  <component :is="item.type" :key="item.id">
    <template v-slot:[item.slotName]>{{ item.content }}</template>
  </component>
</div>
注意：这里的 :key="item.id" 绑定在 <component> 上， 但真正需要唯一标识的是包含插槽内容的父容器。

四种解决方案

方案一：确保 key 正确绑定

<!-- ✅ 正确：key 在模板根元素上 -->
<template v-for="item in sortedItems" :key="item.id">
  <component :is="item.type">
    <template #[item.slotName]>{{ item.content }}</template>
  </component>
</template>

方案二：替换数组引用触发更新

// ❌ 错误：直接修改
this.items.sort((a, b) => a.order - b.order)

// ✅ 正确：替换引用
this.items = [...this.items].sort((a, b) => a.order - b.order)

// 或使用 computed
const sortedItems = computed(() => {
  return [...items.value].sort((a, b) => a.order - b.order)
})

方案三：使用复合 key

<!-- 使用动态值组合确保 key 唯一 -->
<div v-for="item in sortedItems" :key="`${item.id}-${item.slotName}`">

方案四：强制响应式更新

import { nextTick } from 'vue'

async function forceUpdate() {
  show.value = false
  await nextTick()
  show.value = true
}

完整 Vue 3 示例

<template>
  <div>
    <button @click="sortByOrder">按顺序排序</button>
    <button @click="sortByName">按名称排序</button>
    
    <!-- ✅ key 在模板根元素上 -->
    <template v-for="item in sortedItems" :key="item.id">
      <component :is="getComponent(item)">
        <template #[item.slotName]>
          <span>{{ item.content }}</span>
        </template>
      </component>
    </template>
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'

const items = ref([
  { id: 1, slotName: 'header', content: 'Header A', order: 3 },
  { id: 2, slotName: 'body', content: 'Body B', order: 1 },
  { id: 3, slotName: 'footer', content: 'Footer C', order: 2 }
])

// ✅ 使用 computed 确保排序后触发响应式更新
const sortedItems = computed(() => {
  return [...items.value].sort((a, b) => a.order - b.order)
})

const sortByOrder = () => {
  items.value = [...items.value].sort((a, b) => a.order - b.order)
}

const getComponent = (item) => 'div'
</script>

关键点总结

  1. key 绑定位置：放在 <template> 根元素上
  2. 数组更新方式：使用 [...arr] 创建新数组
  3. computed 排序：自动追踪依赖，触发更新
  4. 动态插槽名：确保与响应式数据同步变化

错误方案 vs 正确方案对比

场景错误方案正确方案
key 绑定 :key="item.id" 在 component 上 :key="item.id" 在 template 上
数组排序 arr.sort() arr = [...arr].sort()
动态插槽 v-slot:[item.name] 单独使用 配合稳定的 key 和响应式数据
强制更新 vm.$forceUpdate() ref.value = [...ref.value]
